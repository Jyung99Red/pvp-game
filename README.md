# 放置地牢

一个直接运行在浏览器中的放置养成与空间动作 RPG。玩家可以建设基地、装备和强化角色、探索地下城，也可以进入独立训练场练习操作，或通过 WebRTC 与另一名玩家进行 PVP。

项目使用原生 HTML、CSS 和 JavaScript，没有打包器、模块系统或安装步骤。

## 开始运行

Windows 下直接双击项目根目录的 [Run-Game.bat](Run-Game.bat)。脚本会自动启动本地服务并在默认浏览器打开游戏；保持脚本窗口开启即可继续游玩，关闭窗口会停止服务。

脚本需要系统已安装 Python，并会自动尝试 `py` 和 `python`。也可以在项目目录手动运行：

```powershell
python -m http.server 8422
```

然后打开 [http://localhost:8422](http://localhost:8422)。页面 partial 和资源清单通过 `fetch()` 加载，因此不能直接使用 `file://` 打开 `index.html`。

游戏启动、基地、PVE 和训练场都不依赖网络。只有创建或加入 PVP 房间时才需要联网，页面会在此时加载 PeerJS 并建立连接。

## 游戏内容

- **基地**：查看角色属性和装备，管理设施、背包、商店与铁匠铺。
- **地下城**：连续挑战普通怪物与 Boss；本轮金币需要安全回城后才会入账，阵亡会丢失尚未带回的金币。
- **走位训练场**：使用固定属性练习移动、轻击、蓄力、格挡和四向技能，不读取或修改养成存档。
- **玩家对战**：支持公平对决和养成对战。主机创建 4 位房间号，另一名玩家输入房号加入；主机负责最终战斗判定。

房间号用于临时匹配，不是访问密码。断线或页面退出后，当前 PVP 对局不会恢复。

## 战斗操作

- 中央操作区拖动移动，短按松手轻击。
- 在原位按住进入蓄力；蓄力后可以拖动走位和转向，在取消圈外松手释放重击，回到圈内松手取消。
- 左侧按住防御，拖动改变面向；防御时仍可用中央操作区移动。
- 右侧四向技能：上治疗、右疾速、下满蓄、左弹反。
- “中心松手取消”和“自动朝向怪物”可在战斗设置中调整。

更完整的手势、技能和数值说明见 [战斗操作与调参](pve/COMBAT_CONTROLS.md)。

## 测试

运行完整的战斗与启动回归：

```powershell
node --test tests/client-boot.test.cjs tests/spatial-engine.test.cjs tests/pve-spatial.test.cjs tests/pvp-spatial.test.cjs
```

自动测试覆盖资源启动、共享空间引擎、PVE 生命周期和 PVP 同步。触屏手感、锁屏恢复、设备旋转和双设备网络体验仍应在真实设备上检查。

## 项目结构

```text
core/       共享状态、存档、规则、几何和启动逻辑
ui/         基地 UI、共享战斗输入与绘制
pve/        地下城档案、空间引擎、训练场和 PVE 流程
pvp/        双人判定、网络同步、房间和 PVP UI
partials/   启动时挂载的页面片段
tests/      启动、共享引擎、PVE 与 PVP 回归测试
```

详细的现行职责和数据流见 [战斗架构](structure.md)。迁移边界与模式差异记录在 [PVE 空间战斗](pve/SPATIAL_MIGRATION.md)、[PVP 空间战斗](pvp/SPATIAL_MIGRATION.md) 和 [训练场说明](pve/TRAINING.md)。

新增或删除脚本、样式及正式页面 partial 时，需要同步更新 `client-assets.json`。所有脚本按清单顺序作为全局经典脚本执行。
