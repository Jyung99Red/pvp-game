# 放置地牢

一个直接运行在浏览器中的放置养成与空间动作 RPG。玩家可以建设据点、装备和强化角色、在区域地图中探索和战斗，在据点的训练场练习连招，或通过 WebRTC 与另一名玩家进行 PVP。

项目使用原生 HTML、CSS 和 JavaScript，没有打包器、模块系统或安装步骤。

## 开始运行

Windows 下直接双击项目根目录的 [Run-Game.bat](Run-Game.bat)。脚本会自动启动本地服务并在默认浏览器打开游戏；保持脚本窗口开启即可继续游玩，关闭窗口会停止服务。

服务监听所有网卡。手机和电脑连在同一个网络时，用脚本窗口里“Phone on the same network”那一行的地址在手机浏览器打开即可。

脚本需要系统已安装 Python，并会自动尝试 `py` 和 `python`。也可以在项目目录手动运行：

```powershell
python -m http.server 8422
```

然后打开 [http://localhost:8422](http://localhost:8422)。页面 partial 和资源清单通过 `fetch()` 加载，因此不能直接使用 `file://` 打开 `index.html`。

游戏启动、据点、PVE 和训练场都不依赖网络。只有创建或加入 PVP 房间时才需要联网，页面会在此时加载 PeerJS 并建立连接。

## 游戏内容

- **据点**：安全区域。走近建筑点击中央键交互：温泉、铁匠铺、商店、仓库、建设管理和训练场。
- **区域冒险**：在区域地图中行走，接触怪物即原地开战；击败首领解锁新区域，奖励当场入账。
- **训练场**：据点里的建筑，与测试木桩打一场正式战斗，招式表、参数和装备与实战完全相同；不发奖励、不会阵亡，屏幕上显示派生树和当前招式。
- **玩家对战**：支持公平对决和养成对战。主机创建 4 位房间号，另一名玩家输入房号加入；主机负责最终战斗判定。

房间号用于临时匹配，不是访问密码。断线或页面退出后，当前 PVP 对局不会恢复。

## 战斗操作

出招是一棵派生树：每一段都是独立的一招，有自己的前摇、挥动和后摇；下一段出哪一招，由**轻点、长按、停顿**三种输入决定。

- **拖动**中央操作区移动。探索时轻点只用于和建筑交互，不会出招。
- **轻点**（`T`）出招。挥动结束（或这一招已经命中）之后再轻点，会在后摇的派生点接上下一段；狂点没有用，挥动结束前的按键会被丢弃。
- **长按**（`H`）：
  - 起手长按是蓄力斩：蓄力中可以拖动走位和转向，松手出招。没有取消圈，想放弃蓄力请按防御。
  - 连段中间长按是切换到该节点的长按招：按住到时间（约 0.25 秒）就自动出招，不用松手；之后松手不会再触发。
- **停顿**（`-`）：某些节点在后摇结束后故意不按，等武器闪光（停顿线）再轻点，会出另一招。
- 连段中拖动中央键只转向；后摇结束时还拖着，就开始移动并中断连段。受击、举盾、放技能也会中断连段。
- 招式与派生（初版，所有武器共用）：

  | 输入 | 招式 |
  |---|---|
  | `T` → `T T` → `T T T` | 横扫 → 回扫 → 回旋斩（收尾） |
  | `T T - T` | 连刺（停顿派生） |
  | `T T H` / `T H` | 下劈 / 上挑 |
  | `H` → `H T` | 蓄力斩 → 追斩 |

- **防御**：左侧按住举盾，拖动改变面向，可同时用中央操作区慢速移动。举盾会消耗**格挡条**：举盾扣一点、按住持续扣、挡下攻击按伤害扣；举盾后很短时间内挡下就是完美弹反，扣得更少并反击。格挡条扣空后要回到四成才能再举盾。格挡能打断后摇和蓄力，打断不了前摇和挥动。
- **技能**：右侧四向技能，上治疗、右疾速、下满蓄、左弹反，消耗技能点。
- 战斗设置里可以调整“中心松手取消技能”“自动朝向怪物”和“音效”。

## 测试

运行完整的战斗与启动回归（Node 自己展开通配符，加测试文件不用改这行）：

```powershell
node --test "tests/*.test.cjs"
```

自动测试覆盖资源启动、共享空间引擎、PVE 生命周期、区域行走/传送门/建筑交互和 PVP 同步。触屏手感、锁屏恢复、设备旋转和双设备网络体验仍应在真实设备上检查。

## 项目结构

```text
core/       共享状态、存档、规则、几何和启动逻辑
ui/         共享 UI、战斗输入与绘制
pve/        区域模拟、空间引擎和 PVE 流程（含据点训练场）
pvp/        双人判定、网络同步、房间和 PVP UI
partials/   启动时挂载的页面片段
tests/      启动、共享引擎、PVE 与 PVP 回归测试
```

进行中的设计笔记在 `docs/tasks/`。

新增或删除脚本、样式及正式页面 partial 时，需要同步更新 `client-assets.json`。所有脚本按清单顺序作为全局经典脚本执行。
