# 方块骑士（Block Knight）

方块风格的 3D 动作 RPG，在手机浏览器里横屏玩。从据点出发，穿过传送门去野外打怪、打首领、开宝箱，带着材料回来打造装备，再去更远、更暗的地方。
也可以和另一台手机联机对战。

项目使用原生 HTML、CSS 和 JavaScript，没有打包器和安装步骤；3D 画面用 three.js，联机用 PeerJS，都已放在 `vendor/` 里，离线也能打开。

2026-10-01～02 按 6 个里程碑重建完毕，之后的路线见 [docs/tasks/roadmap.md](docs/tasks/roadmap.md)。2D 竖屏的旧版本在标签 `v1-2d`（提交 `2a313c4`）。

## 开始运行

Windows 下直接双击项目根目录的 [Run-Game.bat](Run-Game.bat)。脚本会启动本地服务并在默认浏览器打开游戏；保持脚本窗口开启即可继续游玩，关闭窗口会停止服务。

服务监听所有网卡。手机和电脑连在同一个网络时，用脚本窗口里“Phone on the same network”那一行的地址在手机浏览器打开即可。

脚本需要系统已安装 Python，并会自动尝试 `py` 和 `python`。也可以在项目目录手动运行：

```powershell
python -m http.server 8422
```

然后打开 [http://localhost:8422](http://localhost:8422)。资源通过 `fetch()` 和 `import()` 加载，不能直接用 `file://` 打开 `index.html`。

## 操作

只支持横屏，竖屏时会提示把手机横过来。Android 上第一次触摸会请求全屏。

| 操作 | 触屏 | 键盘 |
|---|---|---|
| 移动 | 左下角区域按下出现摇杆，拖动；连续走 1.5 秒后自动变成慢跑 | WASD 或方向键 |
| 攻击：点一下是 A，按住约 0.2 秒是 B | 右下大按钮 | J |
| 副手（药水或火把；带盾或空着时是灰的） | 攻击键上方，按钮上画着副手的图标 | K |
| 格挡（带盾用盾挡，没带盾用武器挡） | 攻击键左边，按钮上画着盾或剑 | L |
| 交互（进建筑、泡温泉、过传送门、开宝箱、点燃枯木丛、采矿采草药） | 左上方；按钮上写着现在能做什么 | E |
| 菜单（人物、装备和背包、暂停、联机对战、设定、重新开始冒险） | 左上角小方键 | Esc |

最多同时两个触点（左右拇指）。底部正中显示帧率、绘制调用次数和三角形数量，方便在手机上看性能。

左上角菜单键右边是**昼夜表**：太阳形的表盘，正午在上、半夜在下，指针一天（20 分钟）转一圈；外圈的颜色是那个钟点的光——白天绿、日出日落橙、夜里蓝；左下的角标是太阳或月亮。
夜里画面偏蓝偏暗、颜色淡一些，野外不带火把也看得见；举着火把时身边是原来的颜色。

## 世界

游戏从**曙光村**开始，这里没有怪物。四栋房子：

- **温泉**：按交互键泡一下，生命回满。
- **仓库**：打开菜单里的背包（只有一个背包，带着的就是全部）。
- **商店**：买药水、火把和隐形戒指，把材料卖掉换金币。
- **铁匠铺**：用金币和材料打造装备。

村子的门都是传送门：站在门前，交互键上写"前往"，按下就过去。门朝哪边，那个地方就在哪边。

- **北门 → 晨雾原野**：哥布林和野狼在各自的家附近巡逻。走进发现距离，它们会停一下、头上出"!"，然后追过来：贴身时出近身的招，隔着一段距离会扑过来或者再走近；出招前地上会出现红色预警区，越来越浓，躲开或格挡。隔着 2 格以上的墙它看不见你；发现以后会绕过墙追过来。
  生命降到三成会狂暴（更快、更痛）。追到离家太远它就掉头回家，边走边回血，这时候打它也不回头，到家生命回满；首领也一样。
  东北角围起来的营地里守着首领**哥布林头目**。打倒它之后，营地里的宝箱和通往灰岩谷的门才会打开。
- **原野首领院子的北门 → 灰岩谷**（打倒哥布林头目之后）：碎石地，一条小溪把谷分成东西两岸，西岸的路通到千柱窟；东岸有一群野狼，东北角的石窝里守着首领**狼王**和它的宝箱。村子没有直通这里的门。
- **灰岩谷北墙 → 千柱窟**：没有日光，不点火把只隐约看得出墙和路，怪物只剩灰影。柱子间爬着**洞穴蜘蛛**：举起两条前腿往正前方扎（往侧边走躲得开，后退躲不开），隔得远会整只扑过来。藏宝室被一排枯木丛封住，用点燃的火把烧掉才进得去。
- **东门 → 训练场**：训练木桩站在空地东边，主角走近 3 格以内它就轮流出招（快斩、重击）。木桩和主角在训练场都不会倒下，打空会回满。

怪物倒下会掉金币和材料，弹出来落在地上，走近了会自己飞过来被捡起（离开区域时没捡的就没了）。宝箱要按住交互键一会儿才打开。
首领打倒后不会自己回来，它站的地方会出现一座**坟墓**：带着它要的材料（头目要哥布林耳 6 个，狼王要狼皮 6 个）按住交互键，坟墓发光几秒后消失，首领从地下升上来，再打倒它还会掉獠牙或牙；离开区域它就又不见了。

野外还能**采集**：原野和山谷的石头边有带橙色斑点的**铁矿**，空地上有带红果的**草药**丛，千柱窟里有长着晶体的**晶石**。
走到旁边按住交互键（铁矿约 1 秒，草药一下就好），东西会弹出来飞到身上；铁矿和晶石采完变成碎石地。
采过的地方过 5 分钟游戏时间、下次再进这个区域时会长回来（站在原地等不会长）。烧掉的枯木丛则一直是烧掉的样子。
有怪物在追你、打你的时候照样能交互：过传送门、采集、开宝箱都行。

在区域里生命打空就倒下，之后回到据点，生命是满的，捡到的东西都还在。平时回据点要走传送门。

主角走到墙、屋顶、树冠后面被挡住时，挡在前面的那一块会变得半透明。

## 装备和物品

主角没有等级，变强只靠装备。装备有四个栏：**主手**（武器）、**副手**（盾、火把或药水）、**护甲**、**饰品**。

| 装备 | 栏 | 加成 | 从哪来 |
|---|---|---|---|
| 木剑 | 主手 · 剑 | 攻击 +8 | 开局带着 |
| 铁剑 | 主手 · 剑 | 攻击 +16，和木剑一样长 | 铁匠铺（要铁矿石） |
| 刺客短刃 | 主手 · 短刃 | 攻击 +11，刀短要贴近，但出招快、招式不同（见"战斗"） | 铁匠铺（要铁矿石） |
| 木盾 | 副手 | 防御 +2 | 开局带着 |
| 铁盾 | 副手 | 防御 +6 | 铁匠铺（要铁矿石） |
| 布甲 | 护甲 | 防御 +2、生命 +20 | 开局穿着 |
| 铁甲 | 护甲 | 防御 +7、生命 +40（加了肩甲和胸甲） | 铁匠铺（要铁矿石） |
| 头目护符 | 饰品 | 生命 +50 | 铁匠铺（要头目獠牙和草药） |
| 狼牙项链 | 饰品 | 攻击 +4 | 铁匠铺（要狼王之牙和晶石） |
| 隐形戒指 | 饰品 | 怪物察觉不到你；一出手就失效，脱战 5 秒后重新生效（隐形时人物是半透的） | 商店 |
| 火把 | 副手 | 照亮暗处，能烧掉枯木丛 | 商店 |
| 药水 | 副手 | 喝一口回复三成生命，最多带 5 瓶 | 商店 |

材料：哥布林耳、狼皮、蛛丝（怪物掉）、头目獠牙、狼王之牙（首领掉）、铁矿石、晶石、草药（采集），都能卖给商店。

- **菜单**：左上角小方键或 Esc。**打开时游戏不暂停**（怪物照样会打过来），要停下来就点右边的"暂停"。
  - 左边是自己的 3D 模型，拖动可以转着看；
  - 中间是生命、属性、四个装备栏（主手、副手、护甲、饰品）和背包格子。点一格，下面会写它是什么、加多少、换上以后生命、攻击、防御变成多少。
    **只能在据点里换装备**，在外面打开只能看：出门前想好带盾还是带火把。
  - 右边是暂停、联机对战、设定（点开以后每项一个键，点一下换：音效、帧率显示、画质清晰/极高/省电/自定义、镜头远近，存在这台手机上；自定义时每项画质一个滑块）和重新开始冒险；
    关闭键在右上角。回据点走传送门。
  - 装备的图标是用装备的 3D 模型画的；材料和饰品用表情符号。
- **商店**：药水 15 金币一瓶，火把 30 金币，隐形戒指 150 金币；材料按个卖，也可以一次全部卖掉。
- **铁匠铺**：能马上打造的亮着；选中后会列出要的金币和材料，够的是绿色、不够的是红色。
- 副手放什么：
  - **盾**：按格挡键时用盾挡，比用武器挡更稳（见下面"战斗"）。
  - **火把**：按副手键点燃，再按一下熄灭。点燃的火把照亮周围；带着火把对着枯木丛按交互键，火把和枯木丛一起点着，火会烧到相邻的枯木丛，烧完通路就开了，而且一直保持烧掉的样子。拿着火把时只能用武器挡，也不能拿火把打。
  - **药水**：按副手键喝一口，约 0.8 秒，喝的时候慢走。被打中会洒掉这一口（瓶子不少）。出招中按下会等这一招结束再喝。副手键右上角是剩几瓶，喝光了按钮变灰。

## 战斗

出招是一棵派生树：每一段都是独立的一招，有前摇、挥动、后摇；下一段出哪一招，由 **A、B、停顿** 决定。
只有挥动段的武器碰到身体才算命中，判定跟着 3D 模型的骨骼走，所以刀长刀短直接决定够不够得着。

招式表跟着**武器类型**走，操作方式一样，招不一样。

**剑**（木剑、铁剑）：稳重，射程远，B 招击退、失衡 2 点。

| 输入 | 招式 |
|---|---|
| A → A A → A A A | 斜斩（右上斜劈到左下）→ 回扫（挥回右上）→ 重斩（举剑过头劈到左下，收尾） |
| A A ·（停一下）A | 连刺 |
| A B / A A B | 上挑 / 下劈（击退并累积失衡） |
| B（按住蓄力，松手出招）→ B A | 蓄力斩（剑搭在肩后，松手低低横扫一大圈）→ 追斩 |

**短刃**（刺客短刃）：出招快一截，要贴近，连段最长 6 段；失衡只有 1 点，靠手数。

| 输入 | 招式 |
|---|---|
| A → A A → A A A → A A A A → A A A A A | 斜切 → 反切 → 直刺 → 旋刃 → 落刃（收尾，拿刀的手举过头往下劈，击退） |
| 连段中按 B | 挑刃，挑完还能按 A 接旋刃、落刃（例如 A A A B A A） |
| A A ·（停一下）A | 退步斩：边砍边往后跳 |
| B | 突刺：往前冲一大步刺出去，接 A 进反切 |

- 攻击键点一下是 A，按住约 0.2 秒是 B（剑的起手 B 继续按住就是蓄力）。判定点按还是长按的那一小段时间算在前摇里，所以招不会因此变慢；判定时人站住，只能慢慢转身。
  出招中提前按的下一下会缓冲（只留最后一个），到派生点接上；按得早不会让招变快。停顿派生按"按下"的那一刻算。
- 出招中摇杆不走；前摇里能慢慢转身瞄准，挥出去以后（挥动和后摇）就不能转了。后摇结束时还推着摇杆就走开，连段中断。
- 后摇结束后故意停一下，等剑闪白（停顿线）再按 A，出的是连刺。
- **视野**：只看得见人物前方 150° 和身边一小圈（2.5 格，身后也算），而且会被 2 格以上高的墙、树、房子挡住。看不见的地面和上面的方块、花草、石头一起变暗，那里的怪物不画（红区和血条也没有），转过身或绕过去就看见了。
- **格挡**：按住格挡键挡住正面 120°（左右各 60°，更偏的方向和背后挡不住），可以慢慢走；刚举起的一小段时间内挡下 = 完美弹反（反击并给对方失衡，盾或武器手会往前推一下，不耽误接着出招）。
  带盾用盾挡；没带盾（副手是火把、药水或空着）用武器挡，挡住掉的血更多、格挡条扣得更多、完美弹反的时机更窄。
  格挡会扣格挡条，按住持续扣，挡下一击按伤害扣；扣空后要回到四成才能再挡。蓄力中按格挡键会丢掉蓄力、立刻格挡；
  出招中按下要等这一招的后摇结束才举起（这期间按攻击键不出招，松开格挡键就取消）。
- 失衡满了（普通怪 3 点，首领 10 点，右上角的失衡格），木桩或怪物硬直 1.5 秒。只有 B 招和完美弹反给失衡；B 招还会把怪物击退。怪物不会被打出硬直，挨打时照样出招。
- 跑步时出招会站定，格挡会变成慢走，都会结束跑步。
- 隔着石头、墙，双方都打不到对方。

| 怪物 | 招式 |
|---|---|
| 哥布林 | 乱挥（右到左横扫，范围宽、距离近）、猛扑（举棍跳过来往下砸，距离远一些） |
| 野狼 | 撕咬（近身咬）、扑击（从约 4 格外整个身体扑过来，预警是一条长带） |
| 哥布林头目（首领） | 横扫、震地（双手举棍往前砸，前摇最长、最痛）、猛扑（跳得比哥布林远） |
| 狼王（首领） | 撕咬两次、扑击（从约 6 格外扑过来） |

## 联机对战

两台手机对打，公平对决：开打前各自选武器（剑或短刃），其余都是开局装备（木盾、布甲），不读存档，不能带药水和火把。

1. 两台手机都打开游戏，并且都能上网：配对要经过 PeerJS 的免费公共服务器，配对之后两台手机直接互传数据。
   在同一个 Wi-Fi 下，两台手机都可以打开电脑上 `Run-Game.bat` 显示的那个地址。
2. 一台点左上角菜单 →"联机对战"，选好武器，点"创建房间"，屏幕上出现 4 位房间号。
3. 另一台点"联机对战"，选好武器，点"加入房间"，用数字键盘输入房间号，点"加入"。上次选的武器会记住。
4. 连上后两边自动进竞技场，倒计时 3 秒开打。创建房间的一方是主机，所有命中都由主机判定。

- 每台手机都把自己画成蓝衣、对方画成红衣。视野和冒险里一样：墙后和身后的对手不画，自己看不见的地面会变暗；对手在视线里但跑出屏幕时，屏幕边缘有红色箭头指着他。
- A 招打中对方只扣血、不打断，双方可以互换轻击；B 招打中会打断对方的连段并把人推开。格挡、弹反和打怪时一样。
- 打开菜单对局不会暂停，菜单里可以认输或离开（离开后回到据点）。手机切到后台（包括锁屏）不会断线：对局停住，对方屏幕上显示"对方暂时离开，等待中…"，
  回来后倒计时 3 秒接着打；离开超过 1 分钟这一局才中断。5 秒收不到对方的消息算断线，都会提示原因。
- 一局结束后两边都点"再来一局"就重新开始。

在一台电脑上试：开两个标签页，地址都加 `?link=local`，两个标签页直接对战，不用联网。
公共服务器连不上时，可以自己搭一个 [PeerServer](https://github.com/peers/peerjs-server)，两边地址都加 `?peer=主机:端口`。

## 存档

存档在浏览器里（`localStorage`）：打倒的首领、开过的宝箱、带着的东西、穿着的装备、烧掉的枯木丛、采过的资源点和游戏时间。
过传送门、打倒首领、开宝箱、倒下、捡东西后、买卖和打造、换装备、切到后台时都会自动存。每次打开游戏都从据点开始，生命是满的。
菜单里的"重新开始冒险"会清除存档（会先问一次）。

地址后加 `?map=base`、`?map=field`、`?map=valley`、`?map=cave` 或 `?map=clearing` 可以直接进指定区域（测试用），加 `?boxes` 可以看到判定盒。

## 动作调试（电脑上用）

服务开着时在电脑浏览器打开 [http://localhost:8422/tune.html](http://localhost:8422/tune.html)，可以边看边调主角的动作：

- 选武器和招式，拖每根骨头的 rx / ry / rz 滑块，人物马上跟着变（左右拖通道名可以微调，按住 Shift 更细）；也能直接在 3D 里点身体选骨头。
  选中的骨头上有红 / 绿 / 蓝三根线，是它自己的 x / y / z（Blender 的 Local，永远互相垂直）；每根骨头下面"绕自身轴"的 X / Y / Z 按住左右拖，
  就是绕这三根线转，什么角度都摆得到，三个数由工具换算。rx / ry / rz 是欧拉角（先 ry、再 rx、最后 rz，相当于 Blender 的 ZXY 欧拉），
  滑块绕的轴和那三根线不一样：鼠标放到滑块上，画面上的虚线就是它的轴。改过的数旁边有"原 … ↺"，点一下只还原这一个数。
- 预览三种：**单招**（从站姿出这一招）、**连段**（按真实的派生时机连着出，可以选现成的或自己拼 A / B / · A）、**其他姿势**（站姿、举盾、横剑格挡、弹反后的前推、喝药、举火把、受击、倒地）。
- 时间轴可以拖、逐帧走、慢放到 0.05 倍；画面上有关键姿势 a / b 的残影、剑的轨迹、判定框、训练木桩。
- 节奏（前摇、挥动、后摇、派生点、踏步）也能实时改。
- "体检"和测试的量法一样：扫过的角度、剑尖起止点和最低点、标准距离打不打得到木桩和人、最远打到多远。
- 改动只在这个页面里生效，浏览器会记住草稿；Ctrl+Z 撤销。每次打开都读文件里最新的数：草稿里已经写回文件的项自动清掉，
  文件在你调过之后又改过的项以文件为准，页面会提示是哪几项，也可以选择还是套用上次的草稿。"复制全部改动"得到能直接贴回 `models/player_moves.js` 和 `game_config.js` 的代码。

## 地图预览（电脑上用）

服务开着时打开 [http://localhost:8422/map.html](http://localhost:8422/map.html)（或加 `?map=field` 直接看某一张）。只能看，不能改：

- 上边和左边是列号、行号；鼠标指到哪一格，左上角显示 `field (23, 5) 野狼 w`；点一下得到 `field (23, 5)`，按住拖一个框得到 `field (20,10)-(30,15)`，自动复制。
- 可以显示怪物的警戒圈和追击圈、传送门通往哪和过来站哪、手机一屏看得到多大、两点之间走路要几秒。
- 地图下拉框第一项是**总览**：所有地图按传送门的方向摆在一起，连线是传送门（虚线要先打倒首领，粉色是两头方向对不上）；点一块区域打开它。
- 想改地图时，把坐标和要改成什么告诉 Claude，由它改 `game_config.js` 里的地图。

地图预览页（每张地图读得出来、坐标和描述、量距离、一屏范围）。

手感、真实帧率、音效、iPhone 行为、两台手机真实联机仍要在真机上检查。

## 项目结构

```text
core/       模拟和数学（不依赖页面和 three.js）：地形、主角、怪物、实体、交互、物品、存档格式、联机协议、启动器
models/     模型数据：骨架、方块、装备、关键姿势、调色板
render/     three.js 画面（地形按 16×16 分块成网格）
ui/         输入层、启动和界面（HUD、菜单和背包、商店铁匠铺、联机房间、设定、音效）
net/        联机通道（PeerJS 和同一浏览器两个标签页之间的本地通道）
tune/       动作调试页（tune.html）：调动作的工作台、3D 预览、面板
mapview/    地图预览页（map.html）：带坐标的只读 2D 地图
vendor/     第三方文件（three.js、PeerJS）
partials/   启动时挂载的页面片段
tests/      Node 测试和浏览器冒烟测试
```

可调数值都在 `game_config.js`，对照表是 `docs/parameters.md`；设计是 `docs/tasks/design.md`，还没定的想法在 `docs/tasks/ideas.md`。
新增或删除脚本、样式及页面片段时，要同步更新 `client-assets.json`。
