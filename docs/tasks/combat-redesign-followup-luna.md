# Luna 执行任务：蓄力时长、冲刺预警与移动控件

日期：2026-09-13。需求依据：`combat-redesign-proposal.md` 的“本轮调整”。状态：已实现，合入 main 时补齐冲刺停止与取消圈定位。三套 Node 回归共 72 项通过，语法/diff 检查通过；本次合并未复跑浏览器操作，真实设备和双设备 PVP QA 仍未覆盖。

## 1. 武器增伤起点后再蓄 2 秒

- 正式 PVE、公平/养成 PVP：`T = chargeThresholdMs / 1000`，`fullCharge = T + 2`，伤害成长比例 `clamp((charge−T)/2, 0, 1)`。低于 T 仍可出基础伤害重击。
- 基础 300ms → 2300ms 满蓄；假设阈值减 50ms → 250ms + 2000ms = 2250ms。保留现有 basic/heavy/light 模板 300/350/280ms，勿把举例当成装备改值。
- 同步蓄力进度、满蓄上限、范围/角度预览、释放快照、满蓄技能与疾速；几何仍按总进度比例增长，最小/最大范围不变。不得混用固定 2 秒和新上限。
- 训练保留独立配置定位；检查共享引擎改动不破坏其蓄力、技能和显示，不额外重调训练平衡。
- 核对 PVP 两侧独立配置、客机预测、快照校验和协议/规则版本，防止不同蓄力规则的客户端匹配。

入口：`core/spatial_profiles.js`、`pve/spatial_engine.js`、`pvp/spatial_duel.js`、`pvp/pvp_logic.js`、`ui/ui_spatial_battle.js`。`spatialProfiles.apply()` 计算 `C.fullCharge = C.chargeThreshold + 2`，消费者追随配置。

## 2. 冲刺预警缩短，接触防御立即结束

- 预警终点在锁向后固定，冲刺中只绘制剩余路径。A→B 行进到中段后不得把终点推到 C；末段缩至终点，到达/受阻/打断立即消失。
- 与墙、场地边界和身体停止规则对齐。使用模拟状态/实际路径驱动显示，不能靠渲染器修改战斗位置。
- 玩家在冲刺前半或后半成功格挡/弹反，都在接触位置结束突进并进入收招或已触发的失衡。自动弹反沿用同一接触停止处理，费用和反击规则维持现状。
- 结算一次伤害/反击后立即处理停止；不得继续位移、穿身、重复命中或等剩余距离耗尽。不要把失衡状态覆盖为普通收招，也不要额外增加每次弹反必然失衡的规则。

入口：`pve/spatial_engine.js` 的 `tickEnemy()` / `enemyHit()`，`ui/ui_spatial_battle.js` 的冲刺绘制，以及 `core/spatial_combat.js` 的路径/碰撞工具。绘制使用剩余 `dashRemaining`；冲刺碰撞不沿墙滑行，部分步长受阻或命中即结束，并保留命中触发的失衡。

## 3. 补全落指处的动态摇杆

- 保留现有主按钮布局和移动/长按蓄力操作。每次按下以落指处为底座中心，摇杆头按拖动方向和距离偏移，限制显示行程；大小、对比度足以让玩家辨认，不被大圈或文字遮住。
- 落指原点、底座、摇杆头各自定位清晰，避免重复叠加偏移。复用现有 `--gesture-x/y` 和手势状态。
- 松手、取消、失去指针捕获、暂停/失焦、旋转尺寸变化后清理显示；保留引擎要求的受击后持续持有移动语义。
- PVE、PVP、训练共用；客机反转视角下摇杆仍跟随屏幕拖动方向。

入口：`ui/combat_input.js`、`ui/ui_spatial_battle.js`、`pve/combat_controls.css`、相关页面样式与 partials。核查 `.pad-knob` 的显示、层级、定位和遮挡；若增加资源，更新 `client-assets.json`。

## 4. 放大蓄力取消判定标记

- 以当前 18 CSS px 半径为基准放大，实施初值采用 **24 CSS px 半径**；这是本任务的实现取值，用户只要求更大、更清楚。
- 实际判定与可见圈共用半径，避免只放大画面造成圈内仍出招。圆心保持本次落指点，描边/底色能与摇杆头区分。
- 圈内（含边界）松手取消，圈外出重击；关闭原位取消时隐藏此标记并保持释放行为。不顺带修改四向技能选择阈值。

入口：`core/combat_gestures.js`、`pve/combat_controls.css`、`ui/combat_input.js`、`ui/ui_spatial_battle.js`。
