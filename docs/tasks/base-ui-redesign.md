## 已交付

- 基地分为资源概览、角色状态、装备、设施与出征入口。显示升级经验进度；设施解锁后可从首页进入；开发工具折叠保留。
- 背包支持全部/装备/材料分类、名称搜索、空状态、已装备置顶与材料用途详情。移除无实际容量限制的“20格”显示和填充空格。
- 背包、物品、建筑、铁匠铺与商店使用同一弹窗样式和层级管理，提供明确关闭按钮、背景点击关闭、Esc、焦点约束与返回焦点。关闭详情回到原列表；打开弹窗时锁住背景操作与滚动。

- `ui/base.css` 维护基地样式，清理 `style.css` 中旧的背包/建筑/弹窗样式。基地相关弹窗由 `partials/base.html` 随基地一起无缓存加载，兼容旧缓存入口中的遗留弹窗。
