# 参数清单（按当前代码）

2026-10-01 按重建后的内容重写（M1 新骨架）。旧的 2D 版本清单在提交 `2a313c4` 的同名文件里，
连招、格挡条、卡肉、伤害等数值搬回来时再逐项补回本文。

本文是 `game_config.js` 的对照表：**数值以 `game_config.js` 为准**，代码改了要顺手改这里。
定位按符号名，不按行号。

## 1. 读表规则

| 来源 | 放什么 |
|---|---|
| `game_config.js` | 所有可调数值：尺度、移速、动画混合、判定相关尺寸、镜头、画质、输入、按钮布局、地图 |
| `models/` | 模型数据：骨骼位置、方块尺寸和颜色名、装备方块、关键姿势。是素材，不是可调数值（`3d-migration-concept.md` 4.3） |
| `core/loop.js` | 模拟步长 `STEP = 0.01` 秒、单帧上限 `MAX_FRAME = 0.1` 秒（属于模拟框架，不调） |
| `render/world_view.js` | 纯表现常量：光照强度、太阳方向、雾、转身倾斜系数 |

单位：位置、距离、速度用世界单位（1 格 = 40），速度是世界单位/秒；时间是秒；角度是弧度；
触屏相关的距离和尺寸是 CSS 像素；模型尺寸和镜头距离是格。

## 2. 尺度 `world`

| 参数 | 值 | 说明 |
|---|---:|---|
| `unitsPerBlock` | `40` | 1 格 = 40 世界单位（`3d-migration-concept.md` 12.1） |

## 3. 主角移动 `player`

| 参数 | 值 | 说明 |
|---|---:|---|
| `speed` | `115` | 摇杆推满时的移速，世界单位/秒（约 2.9 格/秒） |
| `turnRate` | `8` | 朝摇杆方向转身的角速度，弧度/秒（转 180° 约 0.39 秒） |
| `radius` | `12` | 撞墙用的圆半径，世界单位（0.3 格） |
| `runAfter` | `2` | 连续走动这么多秒后开始跑（2026-10-01 用户提出） |
| `runMultiplier` | `2.2` | 跑步速度是走路的几倍（253 世界单位/秒，约 6.3 格/秒） |
| `runRampSeconds` | `0.3` | 从走加速到跑、从跑减回走用的时间 |
| `runStick` | `0.9` | 摇杆至少推到这么多才算"在走"；推得轻（慢走）永远不会变成跑。键盘总是推满 |

"连续走动"在这些时候中断，计时归零、减速回走路：摇杆松开或推得不够、撞墙走不动（实际移动不到走路速度的一半）。贴着墙斜着滑不算中断。

## 4. 动画 `animation`

| 参数 | 值 | 说明 |
|---|---:|---|
| `blendSeconds` | `0.1` | 待机和走路之间的交叉淡化时长 |

步幅不是参数：由走路、跑步的关键姿势算出（支撑脚从前到后走过的距离），改姿势时自动跟着变，不会明显滑步。
当前走路一个完整循环（两步）约 54 世界单位，满速每秒约 4.2 步；跑步约 79 世界单位，每秒约 6.4 步。
走和跑之间按跑步混合度插值，步幅也一起插值。

## 5. 判定相关尺寸 `models`

| 参数 | 值 | 说明 |
|---|---:|---|
| `playerScale` | `1` | 主角整体比例（骨骼位置、方块、姿势位移一起乘）。主角高约 1.9 格 |
| `swordBladeLength` | `0.92` | 剑刃长度，格。剑刃是 `weapon` 盒；连同护手，剑尖离握点约 1.12 格 |

## 6. 镜头 `camera`

| 参数 | 值 | 说明 |
|---|---:|---|
| `yaw` | `0` | 镜头在主角正南，屏幕上方 = 北（-z） |
| `pitch` | `0.96` | 俯角，弧度（约 55°） |
| `distance` | `10.5` | 镜头到注视点的距离，格 |
| `fov` | `34` | 竖直视角，度 |
| `lookHeight` | `0.8` | 注视点离地高度，格 |

## 7. 画质 `graphics`

| 参数 | 值 | 说明 |
|---|---:|---|
| `pixelRatioMax` | `2` | 设备像素比上限 |
| `shadowMapSmall` / `shadowMapLarge` | `1024` / `2048` | 阴影贴图边长；屏幕短边小于 700 CSS 像素算小屏 |
| `shadowExtent` | `12` | 阴影区域半宽，格；跟着主角走，按阴影像素对齐 |

## 8. 输入 `input`

| 参数 | 值 | 说明 |
|---|---:|---|
| `deadZone` | `12` | 摇杆死区，CSS 像素 |
| `ramp` | `32` | 超出死区后再拖多少像素到满速；速度倍率 = `(偏移 - 12) / 32`，最高 1 |
| `stickRadius` | `52` | 摇杆底座半径，也是摇杆头最远的位置 |
| `maxTouches` | `2` | 同时有效的触点数（两根拇指） |
| `keys` | WASD/方向键、J、K、L、E | 桌面键盘：移动、A、B、副手、交互 |

## 9. 按钮布局 `controlsLayout`

圆心位置：`x` 是到 `side` 那一侧安全区边缘的距离，`y` 是到底部安全区边缘的距离；`size` 是直径。单位 CSS 像素。

| 按钮 | side | x | y | size |
|---|---|---:|---:|---:|
| A | 右 | 78 | 72 | 84 |
| B | 右 | 70 | 162 | 72 |
| 副手 | 右 | 176 | 56 | 72 |
| 交互 | 左 | 64 | 196 | 56 |

| 参数 | 值 | 说明 |
|---|---:|---|
| `minGap` | `10` | 按钮之间的最小间距（测试检查） |
| `stick.zoneWidth` / `stick.zoneHeight` | `250` / `190` | 左下角在这块区域里按下出现摇杆（从安全区的左下角量起，一直延伸到屏幕边缘）。2026-10-01 试用后从"左半屏整个高度"缩小 |
| `stick.restX` / `stick.restY` | `120` / `96` | 没按时摇杆淡淡地停在这里（离左、离下） |

右侧三个按钮总高 178（要求不超过 200）。测试在 6 种常见横屏手机尺寸（含刘海安全区）上检查不重叠、不出安全区。

## 10. 地图 `maps`

`maps.clearing.rows`：M1 的方块空地，一行一个字符串，从北到南。`.` 草地，`:` 土路，`1`～`9` 那么多格高的石墙，
`T` 树（树干占一格、高 4 格、挡路；树冠只画不挡），`@` 出生点。可走区域 24×10 格，四周有墙围住（测试检查走不出去）。
