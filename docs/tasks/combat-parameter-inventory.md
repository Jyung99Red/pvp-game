# 参数清单（按当前代码）

2026-10-01 按重建后的内容重写（M1 新骨架）；同日 M2 补回连招、格挡条、卡肉、伤害和训练木桩。旧的 2D 版本清单在提交 `2a313c4` 的同名文件里。

本文是 `game_config.js` 的对照表：**数值以 `game_config.js` 为准**，代码改了要顺手改这里。
定位按符号名，不按行号。

## 1. 读表规则

| 来源 | 放什么 |
|---|---|
| `game_config.js` | 所有可调数值：尺度、移速、动画混合、判定相关尺寸、战斗规则、招式表、训练木桩、镜头、画质、输入、按钮布局、地图 |
| `models/` | 模型数据：骨骼位置、方块尺寸和颜色名、装备方块、关键姿势（含 8 招和木桩两招的关键姿势）。是素材，不是可调数值（`3d-migration-concept.md` 4.3）。招式的形状和射程由姿势决定，测试钉住（`tests/hits.test.cjs`） |
| `core/loop.js` | 模拟步长 `STEP = 0.01` 秒、单帧上限 `MAX_FRAME = 0.1` 秒（属于模拟框架，不调） |
| `render/world_view.js`、`render/effects.js` | 纯表现常量：光照强度、太阳方向、雾、转身倾斜系数、刀光长度、碎屑数量、闪白和震屏时长 |

单位：位置、距离、速度用世界单位（1 格 = 40），速度是世界单位/秒；时间是秒；角度是弧度；
触屏相关的距离和尺寸是 CSS 像素；模型尺寸和镜头距离是格。

## 2. 尺度 `world`

| 参数 | 值 | 说明 |
|---|---:|---|
| `unitsPerBlock` | `40` | 1 格 = 40 世界单位（`3d-migration-concept.md` 12.1） |

## 3. 主角移动 `player`

| 参数 | 值 | 说明 |
|---|---:|---|
| `speed` | `115` | 摇杆推满时的移速，世界单位/秒（约 2.9 格/秒） |
| `turnRate` | `8` | 朝摇杆方向转身的角速度，弧度/秒（转 180° 约 0.39 秒） |
| `radius` | `12` | 撞墙用的圆半径，世界单位（0.3 格） |
| `runAfter` | `2` | 连续走动这么多秒后开始跑（2026-10-01 用户提出） |
| `runMultiplier` | `2.2` | 跑步速度是走路的几倍（253 世界单位/秒，约 6.3 格/秒） |
| `runRampSeconds` | `0.3` | 从走加速到跑、从跑减回走用的时间 |
| `runStick` | `0.9` | 摇杆至少推到这么多才算"在走"；推得轻（慢走）永远不会变成跑。键盘总是推满 |

"连续走动"在这些时候中断，计时归零、减速回走路：摇杆松开或推得不够、撞墙走不动（实际移动不到走路速度的一半）。贴着墙斜着滑不算中断。

## 4. 动画 `animation`

| 参数 | 值 | 说明 |
|---|---:|---|
| `blendSeconds` | `0.1` | 待机和走路之间的交叉淡化时长 |

步幅不是参数：由走路、跑步的关键姿势算出（支撑脚从前到后走过的距离），改姿势时自动跟着变，不会明显滑步。
当前走路一个完整循环（两步）约 54 世界单位，满速每秒约 4.2 步；跑步约 79 世界单位，每秒约 6.4 步。
走和跑之间按跑步混合度插值，步幅也一起插值。

## 5. 判定相关尺寸 `models`

| 参数 | 值 | 说明 |
|---|---:|---|
| `playerScale` | `1` | 主角整体比例（骨骼位置、方块、姿势位移一起乘）。主角高约 1.9 格 |
| `swordBladeLength` | `0.92` | 剑刃长度，格。剑刃是 `weapon` 盒；连同护手，剑尖离握点约 1.12 格 |

## 5b. 战斗规则 `combat`

| 参数 | 值 | 说明 |
|---|---:|---|
| `fighters.player` | HP `360`、ATK `30`、DEF `8` | 装备和成长回来（M6）之前的固定属性 |
| `hitStun` | `0.35` | 没挡住的一击让被打的一方硬直这么久，打断连段 |
| `weaponPad` | `8` | 判定时武器盒每个方向外扩的世界单位（0.2 格）；画出来的武器不变，受击盒不外扩 |
| `damage.defenseConstant` | `17.5` | 伤害 = max(1, round(原始 × (1 - DEF / (DEF + 17.5)))) |
| `damage.blockMultiplier` | `0.4` | 格挡住的一击只受这么多 |
| `damage.parryAtkRatio` | `0.5` | 完美弹反的反击 = ATK × 0.5 |
| `impact.hitstop` | 命中 `0.06`、格挡 `0.04`、弹反 `0.08` | 卡肉：双方计时停住的秒数，所有命中都有 |
| `impact.knockback` | 命中 `10`、格挡 `5`、弹反 `8` | 怪物打玩家、格挡、弹反时的击退距离；玩家招式的击退写在招式表 |
| `impact.knockbackSeconds` | `0.12` | 击退推完用的时间 |
| `stagger.threshold` / `duration` / `parry` | `3` / `1.5` / `1` | 失衡满 3 点硬直 1.5 秒；完美弹反给 1 点 |
| `charge.threshold` / `full` | `0.3` / `2.3` | 起手 B 的蓄力伤害从按下后 0.3 秒开始增长，2.3 秒满 |
| `charge.moveMultiplier` / `turnMultiplier` | `0.6` / `0.65` | 蓄力时走路和转身的倍率 |
| `guard.startup` | `0.16` | 按下副手键到盾举起的时间 |
| `guard.parryWindow` | `0.18` | 盾举起后这么短时间内挡下 = 完美弹反 |
| `guard.moveMultiplier` / `turnMultiplier` | `0.3` / `0.5` | 举盾时走路和转身的倍率 |
| `guard.frontAngle` | `π/2` | 攻击来自正面左右各 90° 以内才挡得住（`3d-migration-concept.md` 待定 3 的暂定） |
| `guardBar.max` | `100` | 格挡条满值 |
| `guardBar.raiseCost` / `holdDrain` | `10` / `10` | 举盾扣 10；按住每秒扣 10 |
| `guardBar.blockCostScale` / `parryCostRatio` | `6` / `0.5` | 挡下一击扣 原始伤害 / 最大生命 × 6 × 100；完美弹反扣一半 |
| `guardBar.refillSeconds` / `unlockRatio` | `3` / `0.4` | 放下盾 3 秒回满；扣空后回到 40% 才能再举 |

## 5c. 招式表 `combo`

| 参数 | 值 | 说明 |
|---|---:|---|
| `root` | A → 横扫，B → 蓄力斩 | 不在连段里时 A、B 出的招 |
| `pauseAfterRecovery` | `0.2` | 后摇结束后过这么久才算"停顿"，停顿后的 A 走停顿派生 |
| `windowAfterRecovery` | `0.7` | 后摇结束后连段窗口还开着这么久 |
| `recoveryTurnMultiplier` | `0.5` | 后摇里摇杆只转向，转速是 `player.turnRate` 的一半（4 弧度/秒；2026-10-01 用户要求，为了平衡） |
| `bufferSeconds` | `0.4` | 提前按的输入（只留最后一个）超过这么久还没执行就作废；卡肉的时间不算；还按着的 B 不作废（等着出蓄力斩） |

| 招式 | 输入 | 前摇 / 挥动 / 后摇 | 派生点 | 倍率 | 失衡 | 击退 | 踏步 |
|---|---|---|---:|---:|---:|---:|---:|
| 横扫 `slash` | A | .10 / .08 / .30 | .12 | .30 | 0 | 0 | 3 |
| 回扫 `backslash` | A A | .10 / .08 / .36 | .14 | .32 | 0 | 0 | 3 |
| 回旋斩 `spin` | A A A | .16 / .18 / .60 | 无（收尾） | .55 | 0 | 0 | 0 |
| 连刺 `thrust` | A A · A | .12 / .06 / .55 | 无 | .60 | 0 | 0 | 14 |
| 上挑 `rising` | A B | .30 / .10 / .60 | 无 | .70 | 1.5 | 15 | 4 |
| 下劈 `cleave` | A A B | .30 / .08 / .65 | 无 | .80 | 1.5 | 15 | 7 |
| 蓄力斩 `charged` | B（按住蓄力） | .45 / .12 / .60 | .25 | .30 + .80 × 蓄力 | 1 | 18 | 4 + 13 × 蓄力 |
| 追斩 `follow` | B A | .10 / .08 / .45 | 无 | .40 | 0 | 0 | 3 |

时间单位秒，击退和踏步是世界单位。A 招不击退、不给失衡（`3d-migration-concept.md` 第 5 节）；击退和失衡是每招自己的数值，不按键写死。
蓄力 = (按住时长 - 0.3) / 2，夹在 0～1。踏步是挥动段身体沿出招朝向前移的距离（蓄力斩随蓄力变远，待定 5 的暂定）。

招式形状由关键姿势决定（`models/player_moves.js`），测试钉住：横扫、回扫、追斩、蓄力斩、连刺的刀尖水平扫角和 2D 版扇形相差不超过 15°（94°、101°、90°、122°、25°）；
回旋斩 200°～220°，背后留缺口；上挑从左下到右上，下劈从右上到左下。标准距离（中心相距 60 世界单位）上每招都必须打中木桩和人形目标；现在的最远命中距离约 85。

## 5d. 训练木桩 `dummy`

| 参数 | 值 | 说明 |
|---|---:|---|
| `maxHp` / `atk` / `def` | `600` / `24` / `1` | 打空后回满（训练场不会结束） |
| `radius` | `14` | 碰撞圆半径 |
| `engageRange` | `120` | 主角在这么近（3 格）以内时才出招 |
| `firstDelay` / `delay` | `0.8` / `0.45` | 第一招前、两招之间的等待秒数 |
| `clubLength` | `0.9` | 木棍长度，格 |
| `flinchSeconds` | `0.22` | 被打中时往后一仰的时长（改变受击盒，所以算判定层） |
| `moves` | 快斩 1.3 / .16 / .95 倍率 .6；重击 1.6 / .16 / 1.15 倍率 1 | 前摇 / 挥动 / 后摇秒数，轮流出 |

木桩固定在地图的 `D` 处、朝 `maps.clearing.dummyFacing`，不追人、不转向、不被击退；骨骼判定和主角一样。

## 9. 按钮布局 `controlsLayout`

圆心位置：`x` 是到 `side` 那一侧安全区边缘的距离，`y` 是到底部安全区边缘的距离；`size` 是直径。单位 CSS 像素。

| 按钮 | side | x | y | size |
|---|---|---:|---:|---:|
| A | 右 | 78 | 72 | 84 |
| B | 右 | 70 | 162 | 72 |
| 副手 | 右 | 176 | 56 | 72 |
| 交互 | 左 | 64 | 196 | 56 |

| 参数 | 值 | 说明 |
|---|---:|---|
| `minGap` | `10` | 按钮之间的最小间距（测试检查） |
| `stick.zoneWidth` / `stick.zoneHeight` | `250` / `190` | 左下角在这块区域里按下出现摇杆（从安全区的左下角量起，一直延伸到屏幕边缘）。2026-10-01 试用后从"左半屏整个高度"缩小 |
| `stick.restX` / `stick.restY` | `120` / `96` | 没按时摇杆淡淡地停在这里（离左、离下） |

右侧三个按钮总高 178（要求不超过 200）。测试在 6 种常见横屏手机尺寸（含刘海安全区）上检查不重叠、不出安全区。

## 10. 地图 `maps`

`maps.clearing.rows`：M1 的方块空地，一行一个字符串，从北到南。`.` 草地，`:` 土路，`1`～`9` 那么多格高的石墙，
`T` 树（树干占一格、高 4 格、挡路；树冠只画不挡），`@` 出生点，`D` 训练木桩（朝向 `dummyFacing`，现在朝西 π）。可走区域 24×10 格，四周有墙围住（测试检查走不出去）。
