# 参数清单（按当前代码）

2026-10-01 按重建后的内容重写（M1 新骨架）；同日 M2 补回连招、格挡条、卡肉、伤害和训练木桩；M3 加上哥布林、野狼和野外地图（5e 节、第 10 节）；M4 加上竞技场和联机对战（第 10、11 节）。旧的 2D 版本清单在提交 `2a313c4` 的同名文件里。

本文是 `game_config.js` 的对照表：**数值以 `game_config.js` 为准**，代码改了要顺手改这里。
定位按符号名，不按行号。

## 1. 读表规则

| 来源 | 放什么 |
|---|---|
| `game_config.js` | 所有可调数值：尺度、移速、动画混合、判定相关尺寸、战斗规则、招式表、训练木桩、怪物、镜头、画质、输入、按钮布局、地图、联机对战 |
| `models/` | 模型数据：骨骼位置、方块尺寸和颜色名、装备方块、关键姿势（含 8 招、木桩两招、哥布林和野狼各两招的关键姿势），怪物的走路摆腿公式。是素材，不是可调数值（`3d-migration-concept.md` 4.3）。招式的形状和射程由姿势决定，测试钉住（`tests/hits.test.cjs`、`tests/monsters.test.cjs`） |
| `core/loop.js` | 模拟步长 `STEP = 0.01` 秒、单帧上限 `MAX_FRAME = 0.1` 秒（属于模拟框架，不调） |
| `render/world_view.js`、`render/effects.js` | 纯表现常量：光照强度、太阳方向、雾、转身倾斜系数、刀光长度、碎屑数量、闪白和震屏时长、对战时看不见的地面压暗（240 条射线、30 格、不透明度 0.55） |
| `core/duel.js` | 联机协议版本 `PROTOCOL`（改协议时手动加一）；访客最多攒 256 条未确认的操作 |
| `net/link.js` | 房间号 4 位数字、PeerJS 房间名前缀、STUN 服务器（不是可调数值） |

单位：位置、距离、速度用世界单位（1 格 = 40），速度是世界单位/秒；时间是秒；角度是弧度；
触屏相关的距离和尺寸是 CSS 像素；模型尺寸和镜头距离是格。

## 3. 主角移动 `player`

| 参数 | 值 | 说明 |
|---|---:|---|
| `speed` | `115` | 摇杆推满时的移速，世界单位/秒（约 2.9 格/秒） |
| `turnRate` | `8` | 朝摇杆方向转身的角速度，弧度/秒（转 180° 约 0.39 秒） |
| `radius` | `12` | 撞墙用的圆半径，世界单位（0.3 格） |
| `runAfter` | `2` | 连续走动这么多秒后开始跑（2026-10-01 用户提出） |
| `runMultiplier` | `2.2` | 跑步速度是走路的几倍（253 世界单位/秒，约 6.3 格/秒） |
| `runRampSeconds` | `0.3` | 从走加速到跑、从跑减回走用的时间 |
| `runStick` | `0.9` | 摇杆至少推到这么多才算"在走"；推得轻（慢走）永远不会变成跑。键盘总是推满 |

"连续走动"在这些时候中断，计时归零、减速回走路：摇杆松开或推得不够、撞墙走不动（实际移动不到走路速度的一半）。贴着墙斜着滑不算中断。

## 4. 动画 `animation`

| 参数 | 值 | 说明 |
|---|---:|---|
| `blendSeconds` | `0.1` | 待机和走路之间的交叉淡化时长 |

步幅不是参数：由走路、跑步的关键姿势算出（支撑脚从前到后走过的距离），改姿势时自动跟着变，不会明显滑步。
当前走路一个完整循环（两步）约 54 世界单位，满速每秒约 4.2 步；跑步约 79 世界单位，每秒约 6.4 步。
走和跑之间按跑步混合度插值，步幅也一起插值。

## 5c. 招式表 `combo`

| 参数 | 值 | 说明 |
|---|---:|---|
| `root` | A → 横扫，B → 蓄力斩 | 不在连段里时 A、B 出的招 |
| `pauseAfterRecovery` | `0.2` | 后摇结束后过这么久才算"停顿"，停顿后的 A 走停顿派生 |
| `windowAfterRecovery` | `0.7` | 后摇结束后连段窗口还开着这么久 |
| `recoveryTurnMultiplier` | `0.5` | 后摇里摇杆只转向，转速是 `player.turnRate` 的一半（4 弧度/秒；2026-10-01 用户要求，为了平衡） |
| `bufferSeconds` | `0.4` | 提前按的输入（只留最后一个）超过这么久还没执行就作废；卡肉的时间不算；还按着的 B 不作废（等着出蓄力斩） |

| 招式 | 输入 | 前摇 / 挥动 / 后摇 | 派生点 | 倍率 | 失衡 | 击退 | 踏步 |
|---|---|---|---:|---:|---:|---:|---:|
| 横扫 `slash` | A | .10 / .08 / .30 | .12 | .30 | 0 | 0 | 3 |
| 回扫 `backslash` | A A | .10 / .08 / .36 | .14 | .32 | 0 | 0 | 3 |
| 回旋斩 `spin` | A A A | .16 / .18 / .60 | 无（收尾） | .55 | 0 | 0 | 0 |
| 连刺 `thrust` | A A · A | .12 / .06 / .55 | 无 | .60 | 0 | 0 | 14 |
| 上挑 `rising` | A B | .30 / .10 / .60 | 无 | .70 | 1.5 | 15 | 4 |
| 下劈 `cleave` | A A B | .30 / .08 / .65 | 无 | .80 | 1.5 | 15 | 7 |
| 蓄力斩 `charged` | B（按住蓄力） | .45 / .12 / .60 | .25 | .30 + .80 × 蓄力 | 1 | 18 | 4 + 13 × 蓄力 |
| 追斩 `follow` | B A | .10 / .08 / .45 | 无 | .40 | 0 | 0 | 3 |

时间单位秒，击退和踏步是世界单位。A 招不击退、不给失衡（`3d-migration-concept.md` 第 5 节）；击退和失衡是每招自己的数值，不按键写死。
蓄力 = (按住时长 - 0.3) / 2，夹在 0～1。踏步是挥动段身体沿出招朝向前移的距离（蓄力斩随蓄力变远，待定 5 的暂定）。

招式形状由关键姿势决定（`models/player_moves.js`），测试钉住：横扫、回扫、追斩、蓄力斩、连刺的刀尖水平扫角和 2D 版扇形相差不超过 15°（94°、101°、90°、122°、25°）；
回旋斩 200°～220°，背后留缺口；上挑从左下到右上，下劈从右上到左下。标准距离（中心相距 60 世界单位）上每招都必须打中木桩和人形目标；现在的最远命中距离约 85。

## 5e. 怪物 `monsters`

M3 的第一批怪，AI 是 2D 版的最小版本（巡逻、警觉、追击、轮流出招、狂暴、拴绳）。所有数值都是初值，没有经过手感调试。

| 参数 | 哥布林 `goblin` | 野狼 `wolf` | 说明 |
|---|---:|---:|---|
| `maxHp` / `atk` / `def` | `105` / `36` / `3` | `90` / `54` / `2` | 旧值的生命和攻击都乘旧的 `hpScale` 3（见下） |
| `radius` | `12` | `16` | 碰撞圆半径 |
| `speed` | `54` | `78` | 追击、回家的移速（旧版区域地图的值） |
| `turnRate` / `trackTurn` | `3` / `1.6` | `3` / `1.6` | 追击时转身、前摇里跟踪玩家的角速度，弧度/秒 |
| `patrolRadius` / `patrolSpeed` / `patrolRest` | `60` / `16` / `1.4` | `80` / `22` / `1.0` | 巡逻：在家周围这个半径的圆上取路点，慢走过去，到了停一会儿，下一个路点转 2.4 弧度 |
| `alertRange` / `alertSeconds` | `150` / `0.5` | `180` / `0.4` | 玩家进入这个距离就发现，原地转向玩家、头上出"!"这么久，然后追击 |
| `leash` | `260` | `300` | 离家超过这个距离、玩家又在发现距离外，就回家，到家后接着巡逻 |
| `standOff` | `0.85` | `0.85` | 追到下一招出手距离的这个比例就站住，等出招间隔 |
| `firstDelay` / `delay` | `0.3` / `0.45` | `0.3` / `0.45` | 开始追击（或被打醒）后第一招前、两招之间的等待秒数 |
| `flinchSeconds` | `0.22` | `0.22` | 被打中往后一仰（属于判定层）；怪物不吃受击硬直 |
| `enrage.threshold` / `atk` / `tempo` | `0.3` / `1.3` / `1.2` | 同左 | 生命降到 30% 狂暴（不会退出）：伤害 × 1.3，整个时钟（前摇、后摇、移速、间隔）× 1.2 |
| `corpseSeconds` | `2.5`（共用） | | 倒下后躺这么久，再沉入地下消失 |

| 招式 | 前摇 / 锁定 / 挥动 / 后摇 | 倍率 | 踏步 | 出手距离（由动作算） |
|---|---|---:|---:|---:|
| 哥布林 乱挥 `flail` | 1.3 / .4 / .16 / .85 | .6 | 8 | 约 59 |
| 哥布林 猛扑 `pounce` | 1.6 / .5 / .2 / 1.15 | .9 | 36 | 约 83 |
| 野狼 撕咬 `bite` | 1.05 / .3 / .14 / .75 | .6 | 14 | 约 70 |
| 野狼 扑击 `leap` | 1.15 / .35 / .54 / 1.35 | .9 | 150（`ram`：全身撞） | 约 190 |

- 时间单位秒，倍率是每点 ATK，踏步是世界单位。前摇、后摇是旧值加上旧的 `enemyTiming` 补正（前摇 +0.1、后摇 +0.15）；挥动沿用旧的生效时长 0.16，扑击的挥动 = 旧冲刺距离 150 ÷ 速度 280。
- **锁定** `lock`：前摇的最后这么多秒不再跟着玩家转身。
- **出手距离**不是参数：加载时把每招挥动段（连同踏步）扫一遍，攻击盒最远伸到身体中心前方多远（`core/monster.js` 的 `reach`）。地上的红色预警就是同一次扫描里攻击盒在地面投影的凸包。
- **生命和攻击乘 3**：2D 版只给生命乘了 `hpScale` 3、怪物伤害没变（`combat-combo-concept.md` 13 节说过 PVE 会因此明显变宽松，"要保持原来的危险程度可以再把怪物 ATK 也上调"）。这里按那句话把 ATK 也乘 3。主角固定是 PVP 公平属性（HP 360、ATK 30、DEF 8），比旧版 1 级角色强，所以哥布林的生命没再加。
- 挡下怪物一击扣的格挡条照旧按"原始伤害 / 最大生命 × 6 × 100"算：哥布林乱挥约 36、猛扑约 54，野狼撕咬约 54、扑击约 81。扑击最好躲开或弹反。
- 走路步幅不是参数：由腿长和摆幅算，一个循环（两步）= 4 × 腿长 × sin(摆幅)，哥布林约 42、野狼约 40 世界单位。
- 旧版怪物隐藏的行动力（`enemyApMax` 等）没有搬：按旧值它每 2 秒回 1 点、出一招约 2.5 秒，根本不会用完，只是多一套没用的状态。连段概率旧值是 0，也没搬。

## 10. 地图 `maps`

一行一个字符串，从北到南。`.` 草地，`:` 土路，`1`～`9` 那么多格高的石墙，
`T` 树（树干占一格、高 4 格、挡路；树冠只画不挡），`@` 出生点（对战图有两个，按阅读顺序第一个是主机、第二个是访客），`D` 训练木桩（朝向 `dummyFacing`），`g` 哥布林的家，`w` 野狼的家。
每张图有 `name`（界面上显示）；`training: true` 的图里主角生命打空会回满，不会失败；`duel: true` 的图只用于联机对战。
石墙不分高矮都挡刀（中心连线经过就打不中）；至少 2 格高的石墙和树还挡视线（对战时看不见的对手不画）。

| 地图 | 名字 | 内容 |
|---|---|---|

## 11. 联机对战 `pvp`

主机跑整场模拟、判定每一刀；访客发自己的操作，收主机的快照来画，两次快照之间自己往前预测。

| 参数 | 值 | 说明 |
|---|---:|---|
| `countdown` | `3` | 双方准备好到开打的倒计时，秒 |
| `snapshotSeconds` | `0.05` | 主机发快照的间隔（每秒 20 次） |
| `heartbeatSeconds` | `0.25` | 没别的可发时，至少这么久发一次心跳 |
| `timeoutSeconds` | `5` | 这么久收不到对方任何消息就算断线 |
| `replaySeconds` | `0.25` | 访客收到快照后最多往后补算这么久（追到"现在"） |
| `latencySeconds` | `0.15` | 访客估计的单程延迟上限 |
| `historyEvents` | `128` | 主机保留的、访客还没确认收到的事件条数上限 |
| `connectSeconds` | `12` | 连信令服务器、连对方各自的超时 |

对战双方属性固定为 `combat.fighters.player`（HP 360、ATK 30、DEF 8），装备固定为剑和盾，不能带药水。
主角打主角：A 招（没有击退和失衡值的招）命中只扣血和卡肉，不打断；B 招命中让对方硬直 `hitStun` 并按招式击退。
两台手机连上时比较"规则指纹"：`game_config.js` 里除了 `input`、`controlsLayout`、`graphics`、`camera` 之外的全部数值，加上主角模型、姿势和装备数据；不一致就不开打。
