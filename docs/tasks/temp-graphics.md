## 要做

### 2. 天空可见度（预先烘焙）

- **效果**：每个方块面看得到多少天空，就有多亮。洞穴深处、树冠底下、墙和墙之间的窄道、房子和墙脚附近自然变暗，开阔处亮。现在只有墙角变暗，这一项让暗的范围更大、更柔和。
- **做法**：建地形网格时，从每个面（或每个顶点）往上半球发几条射线，沿着方块格子走几格，数有多少条没被挡住。结果乘进顶点颜色，和现在的墙角变暗（`render/terrain_mesh.js` 的 `AO` / `FACE_AO`）一起用。只影响天光那一部分最好；做不到的话，就整体乘一个不太强的系数。
- **什么时候算**：加载区域时算一次；方块被挖掉或烧掉时，只重算附近的区块。千柱窟本来就暗，效果小，但也照样算。
- **验收**：原野的树荫下、灰岩谷的窄道、曙光村的墙脚，能看出变暗而且是渐变的；切换区域不明显变慢。

### 1. 方块光照传播（像 Minecraft 的方块光）

- **效果**：火把、燃烧的枯木丛、洞口的光沿着空格一格一格扩散，能绕过墙角、照进转角，墙后面照样是黑的。和现在火把的真影子叠加：近处是清楚的影子，远一点是柔和的余光。
- **做法**：每个光源一个亮度值，在方块格子里做广度优先的扩散，被实心方块挡住，每走一格减弱一级。结果写进地形网格的顶点颜色（或单独一个顶点属性），带光的颜色。
- **会动的光源**：火把跟着人走。只重算光源附近的区块，而且光源跨过一格才重算，不是每帧都算。
- **验收**：千柱窟举火把站在转角，转角另一边的墙有淡淡的暖光；隔着 2 格以上的墙照不过去；走动时不卡。

### 5. 水面：半透明、环境反射

- **效果**：水潭半透明，看得见水底；表面反射环境（天空色随时间变，夜里是月光色），有缓慢的波纹和高光；火把靠近时水面有一点火光倒影。
- **做法**：水面换成能反光的材质，环境贴图由当前天光颜色生成，跟着昼夜更新；在着色器里加波纹法线，加菲涅尔效果（越斜看越像镜子）。水面现在怎么画，先看 `render/terrain_mesh.js`。
- **验收**：原野中间的水潭白天、黄昏、夜里各截一张图，看起来都像水；帧率不掉。

### 9. 影子更清晰（只在“极高”档）

- 太阳影子贴图 2048 改到 4096（大屏），火把影子 256 改到 512（`graphics.shadowMapLarge` / `torchShadowMap`）。
- **验收**：影子边缘没有锯齿和闪烁。

### 4. 光照探针网格（彩色反弹光）

- **效果**：地面和墙的颜色反弹到旁边的东西上（草地旁偏绿、土墙旁偏暖），白天、夜里、火光都有。
- **做法**：three.js 0.186 的渲染器支持探针网格，但相关的类不在现在打包的 `vendor/three/three.module.min.js` 里，要用 esbuild 把它一起打包进去（只是打包，不改源码，许可证照旧）。每个区域铺一层粗网格（比如每 2～4 格一个探针），加载时烘焙一次；太阳随时间移动后慢慢重烘，比如每过一个游戏小时重烘一部分。
- **风险**：手机上烘焙会让切换区域变慢；先在原野量烘焙要多少毫秒。如果不划算，就降级成只按主角脚下的地面颜色调整天光的“地面色”。
- **验收**：草地上的角色和石块底部带一点绿；切换区域的时间增加不超过约 0.3 秒。
