# 战斗属性与资源重设计讨论稿

日期：2026-09-13。本文是基于当前空间战斗代码的盘点与建议，不代表已修改玩法。完整现值表见同目录 `combat-parameter-inventory.md`。

## 当前兼容性的结论

当前正式 PVE 和两种 PVP 共用玩家档案映射与人类动作引擎，核心属性仍有作用；但不能将旧交换战斗时代的描述当作现行规则。训练使用独立基础数值；公平 PVP 使用固定档案，不读取养成。角色属性在开战时映射到本场配置。

| 属性 | 当前实际作用 | 需要澄清的地方 |
|---|---|---|
| 攻击 | 轻击约 0.3×攻击；重击 0.3～1.1×攻击；弹反反击约 0.5×攻击 | 武器的攻击几何、前后摇现在基本相同，主要差异来自数值和特效 |
| 防御 | 减免 min(原伤害×20%, 防御×0.15)，之后取整且通常至少 1 伤害 | 减伤封顶仅 20%；达到某档伤害的上限后，继续堆防御对该档伤害无收益。格挡另乘伤害系数 |
| 专注 focus | 基础 AP 回复时间为 20/focus 秒每点，SP 回复时间为 30/focus 秒每点 | 不是跑速、转速、攻速或蓄力速度；玩家仅在待机/后摇/硬直期间回 AP，SP 按战斗模拟时间持续累积 |
| 心眼 insight | 弹反窗倍率 max(0.5, 1+0.03×(insight−10))，最终窗不超过 1 秒 | 不增加治疗或技能伤害；只作为弹反判定窗口钩子 |
| 幸运 luck | 每点提供 1% 暴击率，再加装备暴击效果；暴击伤害 1.5× | 基础幸运生效；装备聚合注册表尚未登记 luck，不应直接加装备 luck 字段并假定会生效 |
| 蓄力阈值 | 正式模式伤害从阈值开始线性增加，到 2 秒达到满伤害 | 不是最低出手时间；低于阈值仍可打出约 0.3×攻击。攻击范围/角度依总蓄力比例增长，不依此阈值 |
| 移动/转向 | 独立基础速度 115 世界单位/秒、8 弧度/秒，再乘装备/技能/姿态倍率 | 不由 focus 决定；已注册独立运动特效，但当前物品没有普遍使用 |

例如 focus=10/13/20 时，允许回复的阶段每点 AP 分别需要 2/1.538/1 秒，SP 分别需要 3/2.308/1.5 秒。默认装备弹反基础窗 200ms，心眼 10/20/40 时为 200/260/380ms；公平模式固定 180ms。

同为 100 攻击、蓄力 1 秒时，300ms 阈值重击约 63 原伤害，700ms 阈值约 48；都蓄满 2 秒时同为 110。高阈值目前是中段伤害成长的劣势，而非完整的重型武器手感。

旧 `combatResolver.calcChargeDamage()` 的低阈值 1 伤害、旧格挡最长 2 秒等配置不再驱动空间战斗；不能只调整它们。`action_speed_penalty`、`passive_speed_boost` 保留了注册/显示定义，但没有发现现行战斗消费者。`STAT_REGISTRY` 同样没有 maxHp：基础生命和升级有效，新增装备生命属性前需要补注册。

## 建议先确定的属性职责

1. 保留生命、攻击、防御、暴击等直接属性；防御改为递减收益公式候选 `原伤害 × 100/(100+防御)`，并同步重做装备/怪物防御数值。该公式只是一版候选，不能直接替换后沿用原数值。
2. 现有“速度”明确显示为“行动恢复”，或在决定新职责后统一改名敏捷。第一版建议只影响 AP，移动速度单独列出，避免同一属性同时提高跑速、攻速、资源和追击能力。
3. 如果保留“智力”，建议转向技能充能效率；弹反窗作为独立操作属性，主要由盾牌/词条给小幅修正。这样治疗、疾速、满蓄和护体都能共享智力的用途。这是职责迁移，需要解释旧智慧装备的变化。
4. 武器使用独立的满蓄时间、轻/重前后摇、范围、角度、移动与转向负担。弱化“所有武器同动作，只换攻击值”的情况。
5. 将“蓄力阈值”改名“蓄力增伤起点”，或合并成以总蓄力比例为横轴的伤害曲线；不要留下一个看起来控制出手、实际只控制伤害的名字。

## 技能点按时间回复：建议第一版

用户已明确希望技能充能随时间增加，比 AP 稍慢。以下具体数值与附带规则是建议，尚未实施。

| 项目 | 建议初值 | 原因 |
|---|---|---|
| AP | 基础每 2 秒 1 点，上限 5 | 保留短期动作预算，先不同时大改所有时序 |
| SP | 基础每 3 秒 1 点，上限 3，开局 0 | 充能速度为基准 AP 的 2/3；2 点技能每 6 秒一轮 |
| SP 回复状态 | 活跃战斗内所有存活姿态，包括蓄力、防御、硬直 | 它是技能时钟；AP 仍体现动作间隙。每点基础耗时更长不代表每种操作下实际取得速度都更慢 |
| 命中与弹反奖励 | 第一版移除现有整点奖励，先评估纯时间回复 | 现行为命中 +1/弹反 +1，轻重等额，额外叠加会过快且奖励优势方；自动弹反也会触发奖励 |
| 后续可选奖励 | 成功命中增加 0.25 点进度、手动弹反 0.5，自动护体不返还 | 若纯时间版本过于消极，再用小额进度奖励鼓励接战；需要按攻击去重 |
| 暂停与局外 | PVE 暂停/楼层选择/基地不增长；结束与掉线不增长；PVP设置按现有不停战规则继续增长 | 使用战斗模拟时间，避免切后台或停在选择界面攒技能 |
| 满点 | 停止累计，不隐藏储存额外充能 | 避免满点花费后瞬间返还 |
| 连层/重赛 | PVE同一趟连层保留点数与小数进度；新探索/PVP新局重置 | 延续当前资源跨层定位，并明确新增进度归属 |
| 智力候选 | 每高于10点增加1.5% SP回复速度，最多+25%，下限0.75× | 满加成为每2.4秒1点，仍慢于基准AP。先只接PVE/养成PVP，公平模式固定倍率1 |

“SP比AP慢”建议定义为默认档位的单位回复时间，而非在所有姿态与减速组合下强制比实际AP获取慢。如果要严格比例，可改成 `SP时间=1.5×AP时间`，但这样行动恢复会同时增强技能频率，不适合再独立让智力影响同一回复。

### 技能需要一起重定价

现行治疗 2 点恢复 30% 最大生命；若每 3 秒回 1 点，相当于理论上每 6 秒恢复 30%，持续恢复量 5% 最大生命/秒。现行疾速 2 点持续 10 秒，也会允许无缝续接。这两个数值不能不评估就直接带进定时SP系统。

建议原型：治疗 2 点/20% 最大生命；疾速 2 点/4秒，先保留现有运动增益，蓄力加速作为独立调参项；满蓄 2 点；单次自动弹反 3 点。治疗此时仍可达理论 3.33% 最大生命/秒，必须结合怪物追击压力验证，不能仅凭下调到20%就宣称平衡。是否允许蓄力中即时治疗、是否给治疗施法硬直，可另列一轮，不同时加入过多变量。

实现时将完整点数与小数充能分别表示；PVE/PVP接同一回复帮助函数，但继续由各自生命周期拥有资源。PVP主机确定可花费点数，快照同步充能进度，客机只做预测显示/校正；更新快照校验与规则版本，不能让客机自行生成可消费的权威SP。

## 怪物冲刺与直线位移攻击

建议加入，尤其适合野狼和暗影刺客。当前怪物共享移速47，玩家115；部分“扑击”“突刺”只是原地扇形判定。加入有预告、有锁向、有落空后摇的突进，比单纯提高怪物攻击值更能迫使玩家处理距离。

建议第一版先给野狼一个可横向躲开的扑击，验证后再给暗影刺客更窄、更快的版本。以下是未验证的原型参数，所有距离均为世界单位。

| 参数 | 野狼扑击候选 | 暗影刺客直刺候选 |
|---|---:|---:|
| 前摇预告 | 0.70秒 | 0.55秒 |
| 前摇末段锁向时间 | 0.25秒 | 0.25秒 |
| 最大冲刺距离 | 150 | 180 |
| 冲刺速度 | 360/秒 | 450/秒 |
| 最长位移持续时间 | 约0.417秒 | 0.40秒 |
| 攻击轨迹半宽（不含目标半径） | 18 | 12 |
| 原始伤害系数 | 0.9×怪物攻击 | 1.1×怪物攻击 |
| 收招后摇 | 0.80秒 | 0.90秒 |
| 冲刺再次可用间隔 | 4秒 | 5秒 |

行为约定：接近/选招 → 前摇跟踪 → 锁定直线 → 实际位移并沿路径检测命中 → 后摇。同一次冲刺最多命中一次。预告指示锁向后不能跟着玩家转弯；碰场地边界/墙或目标身体停止，不穿身，落空照常进入后摇。冲刺冷却建议从冲刺启动计算、按模拟时间递减，是否可选招仍需同时满足距离、AP等条件。

当前引擎只支持圆/扇形，敌人在前摇和出招时不移动；这需要新增动作运动描述、冲刺阶段与连续路径命中，不能仅提高 `ai.speed` 或把扇形拉长冒充冲刺。碰撞和攻击轨迹应使用实际走过的路径，防止越过细墙或跨帧穿过玩家却漏判。位移体积和伤害轨迹宽度分开配置，先使用既有身体阻挡规则，不引入穿身突进。

建议普通冲刺可格挡/弹反；手动弹反打断本次突进并进入明确的惩罚后摇。当前PVE弹反通过累计失衡触发打断，并非每次都打断，因此这条是新动作规则，需要单独实现并验证。先不加不可防御冲刺，以免一次改动同时引入多套反制规则。

## 调整顺序与兼容边界

1. 明确属性职责和真实显示名称，清理过期说明；把现值表作为基准。
2. 做时间SP与四技能定价，固定一套公平PVP基准，观察技能频率、治疗收益与绕圈等待。
3. 做野狼突进原型；再分配不同怪物的移动、停靠距离、选招距离与冷却，避免所有怪物共用一个追击模板。
4. 再调武器手感与防御成长；最后重新评估楼层每层+8%与Boss曲线，避免属性经济和操作难度同时无基准地漂移。

旧存档的装备ID、数量、金币与建筑可以继续保留。但升级曾直接累加到已保存的 `baseStats`：如果修改每级成长，必须明确旧角色如何迁移/重算，不能仅改升级函数后假定旧角色自动符合新曲线。公平PVP只用固定档案，养成PVP需升级属性校验/协议；训练目前满蓄1.6秒、正式2秒等差异，应决定训练是操作沙盒还是精确教学档，再统一对应参数。

## 本轮已实施的第一版钩子

截至 2026-09-13，第一阶段已落地：属性键已统一为 `insight`（心眼）与 `focus`（专注），不再保留旧键兼容；专注同时影响 AP 与 SP 回复，SP 基础 3 秒/点、上限 3、按模拟时间累计小数并取消命中/弹反整点奖励；移动倍率通道保留为未来装备/技能的移速钩子。武器阈值模板为 basic 300ms、heavy 350ms、light 280ms，profile 统一使用 `chargeThresholdMs`，不再保留装备显式阈值覆盖。

PVE 已接入数据驱动的直线冲刺动作：野狼扑击和暗影刺客突刺分别使用 150/360、180/450 的距离/速度，具有预告、锁向、真实路径单次命中、墙/边界/身体停止和收招。技能效果与费用暂未改动；防御曲线、全套武器动作差异、各怪物独立冷却和 Boss 参数仍应在下一轮用本文件的表格逐项调节。
