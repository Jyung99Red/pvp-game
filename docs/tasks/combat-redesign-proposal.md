# 战斗规则与本轮调整

更新：2026-09-13。本文只保留当前规则和本轮调整；详细数值见 `combat-parameter-inventory.md`，执行清单见 `combat-redesign-followup-luna.md`。本轮调整已实现。

## 当前规则

正式 PVE 与养成 PVP 共用玩家属性映射，属性在开战时固定；公平 PVP 使用固定档案，训练使用独立基础配置。

| 属性 / 资源 | 作用 |
|---|---|
| 攻击 | 轻击约 0.3×攻击，重击 0.3～1.1×攻击，弹反反击约 0.5×攻击 |
| 防御 | 减免 `min(原伤害×20%, 防御×0.15)`，之后取整，通常至少 1 伤害；格挡另乘伤害系数 |
| 专注 focus | AP 每点耗时 `20/focus` 秒，SP 每点耗时 `30/focus` 秒；不影响移动、转向或蓄力速度 |
| 心眼 insight | 弹反窗倍率 `max(0.5, 1+0.03×(insight−10))`；结合盾牌基础窗，最终不超过 1 秒 |
| 幸运 luck | 每点 1% 暴击率，叠加装备暴击效果；暴击伤害 1.5× |
| 移动 / 转向 | 基础 115 世界单位/秒、8 弧度/秒，再乘装备、技能和姿态倍率 |

AP 只在待机、后摇、硬直期间回复。SP 上限 3，开局 0，活跃战斗中按模拟时间累计小数进度，所有存活姿态均可回复，满点不储存额外进度；命中和弹反不再奖励 SP。PVE 同一趟连层保留点数与进度，暂停、局外、结束不增长；PVP 设置不停战，SP 由主机判定。

四技能维持现值：治疗 2 SP / 30% 最大生命；疾速 2 SP / 10 秒；满蓄 2 SP；单次自动弹反 3 SP。治疗满血拒绝释放，疾速刷新不叠加。

## 本轮调整

### 武器蓄力：起点 + 固定 2 秒成长

武器决定增伤起点 `T = chargeThresholdMs / 1000`，从起点起再蓄 **2 秒**达到满蓄，即 `fullCharge = T + 2`。起点之前仍可释放基础伤害重击，不增加最低出手限制。

| 情况 | 增伤起点 | 满蓄所需蓄力时间 |
|---|---:|---:|
| 基础 | 300ms | 2300ms |
| 假设武器减少 50ms | 250ms | 2250ms |
| 当前 heavy 模板 | 350ms | 2350ms |
| 当前 light 模板 | 280ms | 2280ms |

减少 50ms 是规则示例，不代表把现有 light 模板改成 250ms。伤害成长比例为 `clamp((蓄力时间−T)/2, 0, 1)`；蓄力条、满蓄提示、攻击范围预览和满蓄技能使用同一满蓄上限。范围和角度仍按总蓄力比例增长，不改变最小/最大几何尺寸。以上时间按无疾速的蓄力进度计算，现有疾速倍率继续生效。

### 怪物冲刺：剩余路径预警与即时停止

野狼扑击、暗影刺客直刺已有前摇、锁向、实际位移、沿路径单次命中和收招。本轮修正表现与停止时机，不重新设计怪物数值。

- 冲刺从 A 到 B，锁向后终点固定。怪物走到 AB 中途，预警只显示当前位置到 B 的剩余路程，并逐渐缩短；不能仍画完整长度，使预警越过 B 延伸到 C。
- 到达终点，或被墙、边界、身体碰撞阻挡时，立即停止位移并结束冲刺预警。
- 玩家在冲刺中途格挡或弹反成功，怪物在实际接触处结束本次冲刺；不能等原冲刺时间走完，也不能穿过玩家后继续冲。保留已结算的伤害、反击和失衡结果，同次攻击不重复命中。
- 结束后进入对应收招或失衡状态；已触发的失衡不得被普通收招覆盖。预警标示剩余中心路径；实际扫掠半宽为路径半宽加怪物碰撞半径，玩家需结合模型体积预判。

### 动态摇杆与蓄力取消圈

- 移动按钮保留现有操作：以每次落指位置为原点，显示清楚的摇杆底座与随拖动偏移的小摇杆头，不能只剩一个大圈。松手或取消后复位，下一次落指重新定位。
- 放大蓄力原位取消圈，使边界更易辨认；显示边界与实际取消半径一致，以本次落指点为圆心。圈内松手取消，圈外松手重击；关闭原位取消时隐藏标记并遵守原设置。
- 共用控件的 PVE、PVP 和训练同步修正，保留 PVP 客机屏幕方向转换和移动、蓄力、防御的现有配合。

## 仍有关联的后续事项

以下不属于本轮实现：防御成长曲线、武器独立前后摇、怪物选招与冷却、Boss 平衡，以及时间 SP 下的治疗/疾速频率评估。没有确定新数值前维持现状。

若后续添加装备生命或幸运属性，需要先补属性注册；若调整升级成长，需要处理已保存的 `baseStats`。这两项仍有实现关联，暂保留提醒。
