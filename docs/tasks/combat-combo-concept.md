# 连招系统概念笔记

**状态：概念稿，未实现。** 2026-09-22 起草，2026-09-29 重新整理。
只写设计意图、已定规则和待拍板的问题，不写实现方式。

## 1. 一句话

出招从两个按钮（轻击 / 重击）改成**派生树**：每一段都是**独立的一招**，有自己的前摇、生效、后摇、
倍率和动作表现；下一段出哪一招，由**轻点、长按、停顿**三种输入决定。
单角色 10+ 招是常态，这是重构，不是在现有轻击/重击上挂分支。

## 2. 参考与取舍

| 来源 | 取什么 | 不取什么 |
|---|---|---|
| 魔物猎人 | 派生树：每招只派生固定几招；出手即承诺；怪物的阶段化行为 | 体力条 |
| 街机格斗 | 每招固定的前摇 / 生效 / 后摇（帧数据），不因按得快而变快；输入缓冲 | 搓招指令、帧级精度 |
| 鬼泣 | 同一按键靠长按、停顿分出不同招（停顿连段）；续段从后摇中途接上，连段流畅；每段独立动作与倍率 | 多按键组合、空中连段 |

共同点：**分支来自"节奏与时机"，不是手速，也不是更多按钮**。
本项目只有中央键 + 防御 + 四向技能，所以分支信号只有轻点、长按、停顿三种。

## 3. 每一招的时间轴（已定）

以一记下劈为例：

```
按下 ── 前摇 ── 生效 ── 后摇 ──────────────┐
      举刀往下劈  劈到底   │派生点│   收刀回架势
                  判定     续段从这里接上  不续段才放完
```

- **前摇**：从按下到劈到底。按下那一刻动作就开始，所以手感是即时的；劈到底之前不能做下一步。
- **生效**：劈到底的一刻，做一次命中判定。
- **后摇**：收刀回架势。后摇中途有一个**派生点**：
  - 已经输入了下一段：到派生点立刻出下一招，剩下的后摇跳过（鬼泣式的流畅连段）；
  - 没有输入：后摇完整放完，回到站定。
- 前摇、后摇、派生点**按招式写死**，不受属性和装备影响。

输入何时被接受：

- **生效之前的输入直接丢弃**，不缓冲。这是防拼手速的核心：狂点不会让招变快，也抢不到下一段。
- 生效之后的输入**缓冲一个**，到派生点执行。
- 连段的成本在于**停下来**：不续段要吃满后摇；收尾招没有派生，后摇最长，是一套连段真正的破绽。
- 段数越靠后，动作越重、后摇越长，让玩家不看数字也知道打到第几段。

## 4. 三种输入

记 `T` = 轻点，`H` = 长按，`-` = 停顿。

| 输入 | 判定 |
|---|---|
| `T` 轻点 | 在停顿线之前按下并短按松手 |
| `H` 长按 | 按住达到阈值，松手出招 |
| `- T` 停顿后轻点 | 生效后**故意不按**，让后摇放完，越过停顿线之后、窗口关闭之前再轻点 |

停顿不是蓄力：蓄力是按住不放，停顿是**什么都不按**。
`T T T` 与 `T T - T` 前两段相同，第三段是两招完全不同的招。

以生效为 0 点，下一段的时间分区：

```
0 ──── 派生点 ──── 后摇结束 ──── 停顿线 ──── 窗口关闭
  缓冲→普通续段    │  普通续段  │  停顿续段  │ 回到第 1 段
```

规则：

1. **停顿线必须晚于后摇结束**，由参数保证；否则后摇里缓冲的普通输入会被误判成停顿。
2. **没有停顿派生的节点，停顿后的轻点按普通续段处理**：停顿只解锁新招，不惩罚慢一点的玩家。
3. 越过停顿线时给一个视觉提示（例如武器闪光）。
4. 停顿只接 `T`，不接 `H`；每种武器只有 1～2 个节点带停顿派生。

## 5. 派生树示例

序列长度 ≤ 3，名字与动作仅为占位：

| 序列 | 性质 |
|---|---|
| `T` | 一段：左横扫 |
| `T T` | 二段：右横扫 |
| `T T T` | 三段收尾：回旋 |
| `T T - T` | 停顿派生：连刺（与 `T T T` 是不同的招） |
| `T H` | 二段分支：中途长按，蓄力收尾 |
| `H` | 起手长按：蓄力斩 |
| `H T` | 蓄力斩后追击 |

### 长按的两种身份

- **起手的 `H`**：保留现有完整蓄力，即蓄力中可移动、转向，伤害随蓄力时长增加，"满蓄"技能照旧作用于它。
  **不再有取消圈**：松手就出招。
- **连段中间的 `H`**：只是固定阈值的开关，按够时长就升级成该节点的长按招。
  不能移动，伤害不随时长变化。

## 6. 中断与取消（已定）

- 所有动作一旦开始都不能被移动、技能或下一招取消；**唯一的例外是格挡**。
- 格挡能打断**后摇**和**起手蓄力**，不能打断前摇：前摇一旦开始，这一刀一定劈出去。
  - 后摇里命中已经结算完，直接切到举盾；PVE 与 PVP 共用同一处改动。
  - 起手蓄力还没出手，按格挡就丢掉蓄力、直接举盾。取消圈去掉后，这是放弃蓄力的唯一办法。
  - 不打断前摇：前摇里命中还没结算，撤掉攻击要连带处理动画、范围提示和 PVP 结算流程；
    设计上也会变成"出手随时反悔"。
- 连段在以下情况中断并回到第 1 段：超出窗口、受击、手势锁定为移动、举盾、放技能。

## 7. 防御：格挡条（已定）

**AP 取消**，改为格挡条。格挡条只作用于防御，三处扣条：

| 时机 | 扣多少 |
|---|---|
| 按下格挡（举盾） | 少量，固定值；防止反复点防御碰弹反 |
| 挡下攻击 | 按承受的伤害扣 |
| 完美弹反（举盾后极短时间内挡下） | 比同一击的普通格挡扣得少 |

- 条空后进入锁定：**回复到某个百分比之前不能格挡**，也就不能完美弹反。
- 完美弹反就是现在的"手动弹反"，判定方式不变：举盾后的弹反窗口内挨打即成功。
- 弹反**技能**（左方向，弹反护体）不变，仍然只吃 SP，与格挡条无关。

## 8. 资源

- **AP 取消**：攻击不带资源约束，连段长度由招式表和后摇决定。
- **SP 与连段无关**：SP 只服务四向技能，连段不吃 SP、也不回 SP。
- 敌人侧隐藏的 `enemyApMax / enemyApRegen` 现在实际是怪物出招频率的节流阀，见待定第 2 条。

## 9. 怪物侧（在现有基础上加魔物猎人参考，最简）

现有：巡逻 / 警觉 / 脱战，两招循环（起手-锁定-生效-后摇），连段概率，狂暴。

在此基础上：

- 招式更多，且能**派生**：怪物也有自己的连段，玩家读得出"接下来还有一下"。
- **阶段化**：怒 / 疲劳 / 濒死，同一只怪在不同阶段给出不同的应对。
- **预兆更清楚**：每招起手可读，躲避与反击有依据。

目标：玩家能读出怪物的下一步，而不是背一套固定循环。

## 10. 实现时会改动的现有规则

以下是 `SYSTEMS.md` 或现有代码里的规则，落地时要同步改：

- "手动弹反消耗 AP"（已定条目）→ 完美弹反消耗格挡条。
- 现在格挡扣 1 AP、手动弹反扣 0.5 AP，举盾门槛 1 AP → 换成第 7 节的三处扣条和空条锁定。
- 出招/后摇期间"保留一个最新指令"、后摇结束才执行 → 改为生效前丢弃、生效后缓冲一个、到派生点执行。
- "玩家攻击时序已定，以 `gameConfig.training` 为准"（已定条目）→ 被按招式写死的时序取代，需要你明确推翻。
- 蓄力与防御现在互斥（蓄力中按防御无效）→ 按防御丢掉蓄力、直接举盾。
- 后摇中按防御现在是排队、后摇结束才举盾 → 直接打断后摇举盾。
- 敌人硬直累积现在只认"是不是重击"（`a.heavy`）→ 每招自带硬直值。
- 设置里的"中心取消"（`controls.cancelAtCenter`）不再作用于蓄力，只剩技能使用。
- 行动力条、`getApMax` / `apMax`、`attackApCost` / `guardRequiredAp` / `blockApCost` / `parryCost` 删除或替换。
- `focus` 不再管 AP 回复，需要新作用。
- 竞技场效果 `ap_surge`（深渊领主：双方行动力恢复加速）作废，需要重做。
- PVP 规则版本号要上调。

## 11. 待定

1. **格挡打断后摇 vs 收尾招的破绽**：收尾招后摇最长，本应是连段的破绽；格挡能打断后摇，
   这个破绽就只剩"举盾扣少量条"。倾向：格挡只能从**派生点起**打断后摇，生效到派生点这一段仍然锁死；
   收尾招的派生点放得很晚。
2. **续段的方向**：轻点不带方向，移动又会中断连段，于是整套连段只能朝同一个方向打，敌人一横移就全落空。
   可选：续段一律沿当前朝向（最简单，靠起手瞄准）；或到派生点时按住中央键小幅拖动（不出移动死区）来调方向。
3. **连段中间的 `H` 与拖动**：中央键现在拖出死区就锁定为移动。
   中间的 `H` 在被识别前拖出死区，算移动（中断连段）还是忽略？识别之后拖动是只转向，还是完全不理？
4. **两处输入归属**：
   - 越过停顿线之后按住 `H`：算当前节点的长按派生，还是另起一套、当起手蓄力？
   - 到了派生点，手指还按着、尚未判定是 `T` 还是 `H`：倾向等判定出来再出招，后摇照常继续。
5. **训练场时序**：训练场现在有自己的满蓄时间（1.6 秒）。招式时序按招式写死之后，
   训练场是否用同一张招式表？倾向用同一张，训练才练得到正式手感。
6. **敌人是否保留资源条**：倾向跟玩家一起取消，改成纯时序节奏（起手 / 锁定 / 生效 / 后摇 + 进攻间隔）。
   怪物的 `focus` 换算成进攻间隔，focus 越低间隔越长，保留原来"越慢越稀"的效果。
   `ap_surge` 可改成"双方后摇缩短、敌人进攻间隔缩短"。
7. **格挡条细节**：按格挡减伤前还是减伤后的伤害扣；锁定解除的百分比；是否只在不举盾时回复；回复速度是否由 `focus` 决定。
8. **疾速技能**：现在会加快蓄力速度。蓄力不是前摇，倾向保留。
9. **招式表规模**：每种武器的具体招数与分段上限。倾向先拿一种武器做 8 招左右跑通手感。
10. **训练场**：倾向全部招式免费开放（训练不读养成）。
