# 参数表

`game_config.js` 的对照表，数值以它为准；改了数值顺手改这里。规则是怎么定的、为什么，看 `design.md`。

**单位**：距离和速度用世界单位（1 格 = 40），速度是每秒；时间是秒；角度是弧度；触屏上的尺寸是 CSS 像素；模型和镜头用格。

## 0. 不在 `game_config.js` 里的

| 在哪 | 是什么 |
|---|---|
| `models/` | 骨架、方块、颜色名、装备方块、所有关键姿势。是素材不是数值：招式的形状和射程由姿势决定，测试钉住 |
| `core/loop.js` | 模拟步长 0.01 秒，单帧最多补 0.1 秒 |
| `core/terrain.js` | 分块 16×16；树 4 格高、建筑和传送门 3 格、枯木丛 2 格、矿石和晶石 1 格 |
| `core/duel.js` | 联机协议版本 `PROTOCOL` = 3（改协议时手动加一）；访客最多攒 256 条未确认的操作 |
| `render/` | 纯画面：光照、雾、火把灯（照亮约 7 格）、特效、离镜头 18 格外不画、镜头遮挡透明的半径 1.3 格 |
| `net/link.js` | 房间号 4 位数字、STUN 服务器 |

## 3. 招式 `combo`

| 参数 | 值 | 说明 |
|---|---:|---|
| `windowAfterRecovery` | 0.7 | 后摇放完后连段还能接多久 |
| `bufferSeconds` | 0.5 | 预输入多久没执行就作废（卡肉不算） |
| `windupTurnMultiplier` | 1/3 | 前摇里摇杆能转身，转速是平时的 1/3；挥动开始时方向锁定（用户 2026-10-02） |
| `weapons.sword` | 起手 A 横扫、B 蓄力斩；标准距离 60；停顿 0.15 | 剑。停顿：后摇放完再过这么久才算"停顿"（用户 2026-10-02：从 0.2 缩短一点） |
| `weapons.dagger` | 起手 A 斜切、B 突刺；标准距离 48；停顿 0.2 | 短刃 |

出招中摇杆不走；只有前摇里能慢慢转身（1/3 转速），挥动和后摇里都不能转（用户 2026-10-02）。后摇放完还推着摇杆就走开，连段中断。

标准距离：这种武器的每一招都必须在这个中心距离打中木桩、人形、哥布林、野狼和首领（测试）。

下面两张表：时间是 前摇 / 挥动 / 后摇，派生点从挥动结束算起（"—"是收尾招）；倍率乘攻击力；踏步是挥动时身体移动的距离（负数往后）。

## 8. 联机对战 `pvp`

| 参数 | 值 | 说明 |
|---|---:|---|
| `weapons` | 木剑、刺客短刃 | 开打前各自选一把；其余是开局装备（木盾、布甲） |
| `countdown` | 3 | 开打前倒计时 |
| `snapshotSeconds` | 0.05 | 主机每秒发 20 次快照 |
| `heartbeatSeconds` / `timeoutSeconds` | 0.25 / 5 | 没话说时的心跳；多久没消息算断线 |
| `replaySeconds` / `latencySeconds` | 0.25 / 0.15 | 访客收到快照后最多补算多久；单程延迟估计上限 |
| `historyEvents` | 128 | 主机保留访客还没确认的事件条数 |
| `connectSeconds` | 12 | 连信令服务器和对方的超时 |

规则指纹：`game_config.js` 里除 `input`、`controlsLayout`、`graphics`、`camera` 外的全部数值，加上主角模型、姿势和两套对战装备。

## 9. 镜头、画质、输入、按钮

| 参数 | 值 | 说明 |
|---|---:|---|
| `camera.yaw` / `pitch` | 0 / 0.96 | 镜头在正南，俯角约 55° |
| `camera.distance` / `fov` / `lookHeight` | 11.5 / 34 / 0.8 | 距离（格，用户 2026-10-02 从 10.5 拉远一点）、竖直视角（度）、注视点高度（格） |
| `camera.zoom` | 近 0.85 / 中 1 / 远 1.15 | 菜单"镜头"设定乘在距离上 |
| `graphics.pixelRatioMax` / `saverPixelRatio` | 2 / 1 | 像素比上限；菜单"画质"选省电时用 1，并关掉太阳阴影 |
| `graphics.shadowMapSmall` / `Large` / `shadowExtent` | 1024 / 2048 / 13 | 阴影贴图（短边小于 700 像素用小的）；阴影范围半宽（格） |
| `input.deadZone` / `ramp` / `stickRadius` | 12 / 32 / 52 | 摇杆死区、再拖多少到满速、底座半径 |
| `input.maxTouches` | 2 | 同时有效的触点 |
| `input.keys` | WASD/方向键、J、K、L、E | 移动、A、B、格挡、交互 |

**按钮** `controlsLayout`（圆心到所在一侧和底部安全区边缘的距离、直径）：A 右 78/72 直径 84；B 右 70/162 直径 72；格挡 右 176/56 直径 72；交互 左 64/196 直径 56。
按钮间距至少 10；摇杆在左下角 250×190 的区域里按下出现，没按时停在 (120, 96)。
