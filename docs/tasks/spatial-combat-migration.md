## 1. 当前目标与范围

玩家从 `index.html` 基地进入正式地下城，用左手控制移动、右手控制重击或防御朝向。
战斗占满屏幕，血条、技能与操作按钮悬浮在场内。训练场复用同一套输入、引擎与绘制，
使用固定属性且不读写养成存档。

继续保留装备成长、楼层怪物、Boss、技能、奖励、金币与检查点。
PVP 保留现有判定器和网络协议。空间 PVP、翻滚、障碍物、寻路及新经济系统不属于本任务。
旧 PVE 引擎、界面、回退选择器和训练别名已删除，不再维护第二套 PVE。

## 2. 最新操作约定

本节替代原来的双按钮、原地蓄力、240ms长按识别、向上释放和武器随射程放大的方案。

| 控件／状态 | 当前行为 |
|---|---|
| 左下移动／轻击 | 短按松手轻击，拖出12 CSS px死区移动；持续移动或长按不会变成蓄力 |
| 右下重击 | 独立按钮，按下立即蓄力；拖动只旋转方向，不推动角色 |
| 右下防御 | 位于重击右上方，形成类似X／○的斜向错位布局；按住举盾，拖动只转向，松手撤防 |
| 双指并行 | 左手移动可以与右手蓄力或举盾同时进行；最多两根指针，每个通道只接受一根 |
| 重击与防御互斥 | 蓄力必须先释放或取消，才能开始防御 |
| 蓄力移动／转向 | 默认速度为正常的70%；移动由左手负责，转向由右手负责 |
| 重击释放 | 在重击按钮几何中心18 CSS px之外，任意方向松手出招；使用当前角色朝向 |
| 中心取消 | 重击按钮中心取消区变红，中心内松手取消，不消耗AP；不影响仍按住的左手移动 |
| 满蓄 | 正式模式2秒、训练1.6秒；满蓄不自动攻击 |
| 防御转向 | 不刷新精准防御窗口；左手可同时移动，使用普通移动速度 |
| 出手／后摇／受击硬直 | 保留一个下一条攻防或技能指令，最新输入覆盖旧输入；不积压多次自动攻击 |
| 左手移动等待 | 与攻防缓冲独立，出手／后摇／硬直结束后仍按住则恢复移动；提前松手就停止 |
| 待执行指令的释放 | 等待中的防御提前松手取消；完成的短按保留轻击，完成的重击释放保留蓄力时长与方向 |
| 技能排队 | 执行成功才扣技能点；覆盖或取消未执行技能不扣点 |
| 暂停／取消／受击／结束 | 失焦、暂停、直接命中造成的硬直和结束清除触摸及待执行指令；指针取消不得误发攻击 |
| 撤退／暂停按钮 | 立即执行，不等待收招 |

左手在右手蓄力或举盾期间短按松手不会额外轻击；在无右手输入的后摇期间短按可排队轻击。
普通轻击仍使用自动朝向敌人的规则，重击使用玩家控制的朝向。

## 3. 范围、武器与受击表现

- [x] 重击扇形随蓄力逐渐扩大：默认射程60→103、角度0.28π→0.68π。
- [x] 预览与实际判定共用 `spatialEngine.heavyShape`；释放后固定范围、位置和朝向。
- [x] 武器轮廓和大小固定，绘制长度32世界单位，不随蓄力、射程或后摇伸缩。
- [x] 蓄力时武器处于扇形左侧，释放后在前摇期间向右挥至100%，后摇线性回到原位。
- [x] 轻击保留同方向挥动；伤害仍在前摇结束时按整片范围判定一次，刀身本身不新增碰撞伤害。
- [x] HP下降触发0.28秒受击变红，颜色按模拟时间恢复，暂停时特效冻结。

上述项目表示已实现，当前双指版本的视觉与手感尚待试玩。
轻击前摇／后摇暂为0.10／0.28秒，重击为0.18／0.48秒，后续再调平衡。

## 4. 参数与扩展接口

| 位置 | 当前职责 |
|---|---|
| `pve/spatial_data.js` | 训练预设、玩家动作、各敌人显式招式、基础移速与转速 |
| `core/combat_gestures.js` | 移动死区、重击中心取消区与释放语义 |
| `core/effects.js` / `core/player.js` | 装备移动与转向词条聚合 |
| `pve/pve_profiles.js` | 将装备、成长与怪物数据转换为正式档案 |
| `pve/spatial_engine.js` | 移动、朝向、攻击、HP、AI、技能、指令缓冲与模拟时钟 |
| `ui/combat_input.js` | 三个按钮通道、最多双指、pointer capture与取消 |
| `ui/ui_spatial_battle.js` | 共用只读Canvas/HUD、武器动画与受击颜色 |
| `pve/pve_logic.js` / `pve/ui_pve.js` | 地下城生命周期、技能点、奖励、输入与结果页面 |
| `pve/training.js` | 固定预设的练习入口、开始、暂停和重试 |

基础移速115、基础转速8 rad/s，蓄力移速／转速倍率各0.7。
`config.motion`提供 `move / turn / chargeMove / chargeTurn` 四个独立乘数。
装备词条为 `spatial_move_speed / spatial_turn_speed / charge_move_speed / charge_turn_speed`。
临时buff通过 `spatialEngine.setMotionBuff(battle, id, multipliers, seconds)` 设置：
同id替换、不同id叠乘，持续时间随战斗暂停，下一场不继承。
现有spd仍影响AP恢复，不自动改成走速；现有装备不会自动添加新词条。

详细接口与取消语义见 [操作与调参](../../pve/COMBAT_CONTROLS.md)。
