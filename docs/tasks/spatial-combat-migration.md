## 本轮大致改了什么

1. **战斗迁移**：正式地下城与训练场共用空间引擎，支持真实位置、朝向、攻击范围和走位；接入全部怪物/Boss招式、养成属性、场地效果、奖励和存档。删除旧PVE实现与回退入口。
2. **手机操作**：拆分左手移动/轻击、右手重击/防御/四向技能；移动摇杆随落指定位、松手隐藏；加入死区、防抖、可关闭的中心取消，以及默认关闭的自动朝向设置。
3. **动作和缓冲**：支持移动中蓄力/防御，分别计算减速；出手、后摇、硬直期间只保留最新一条攻防/技能指令。受击取消右手输入，保留仍按住的左手移动，硬直结束续走。
4. **界面和表现**：全屏战斗、半透明血条，行动力/技能点/战斗记录置于血条下方；右侧四宫格、128px移动摇杆、紧凑横屏布局。武器大小固定，扇形随蓄力扩大；加入怪物受击火花/数字和人物橙色硬直特效，消除提示/记录重复。
5. **技能和数值**：治疗2点且满血不扣点；疾速2点，保留蓄力加速并新增移速/非蓄力转速增益；满蓄2点、弹反3点。蓄力转速65%，重击前后摇0.22/0.60秒。
6. **手机恢复和加载**：改为资源清单统一无缓存加载，避免旧代码/样式与新片段混用；补齐零尺寸画布保护、Canvas上下文恢复、后台/页面缓存返回与暂停恢复，训练场返回不再强制刷新。
7. **验证与交付**：更新过时手势/数值测试和DOM模拟，新增最新改动的回归检查，最终38项全部通过；实现及测试已推送main，用户随后确认初步试玩完成。

## 2. 最新操作约定

本节替代原来的双按钮、原地蓄力、240ms长按识别、向上释放和武器随射程放大的方案。

| 控件／状态 | 当前行为 |
|---|---|
| 左下移动／轻击 | 左侧触摸区域落指即定位摇杆，拖出12 CSS px死区移动；松手或取消立即隐藏并清空坐标；轻点松手轻击 |
| 右下重击 | 独立按钮，按下立即蓄力；拖动只旋转方向，不推动角色 |
| 右下防御 | 四宫格左上防御、右上技能、左下重击、右下预留；按住举盾，拖动只转向，松手撤防 |
| 双指并行 | 左手移动可以与右手蓄力或举盾同时进行；最多两根指针，每个通道只接受一根 |
| 重击与防御互斥 | 蓄力必须先释放或取消，才能开始防御 |
| 蓄力移动／转向 | 默认移速70%、转速65%；移动由左手负责，转向由右手负责 |
| 重击释放 | 在重击按钮几何中心18 CSS px之外，任意方向松手出招；使用当前角色朝向 |
| 中心取消 | 默认开启，重击中心18 CSS px内松手取消；「暂停 / 设置 → 玩家操作」可关闭。关闭后重击中心松手也出招 |
| 四向技能 | 上治疗2点、右疾速2点、下满蓄2点、左弹反3点；拖动超过24 CSS px且离开按钮中心24px死区才选中，松手释放；方向边界约7°防抖 |
| 技能中心取消 | 开启时回中心松手取消；关闭时沿用本次最后有效方向；从未拖出死区不释放、不扣点 |
| 朝向设置 | 默认不自动跟踪：普通移动逐渐转向移动方向，停手保留朝向；可开启自动朝向怪物，恢复待机／轻击／举盾起手的自动朝向 |
| 满蓄 | 正式模式2秒、训练1.6秒；满蓄不自动攻击 |
| 防御转向 | 不刷新精准防御窗口；左手可同时移动，移速为正常30%、转速为正常50%，举盾起手同样减速 |
| 出手／后摇／受击硬直 | 保留一个下一条攻防或技能指令，最新输入覆盖旧输入；不积压多次自动攻击 |
| 左手移动等待 | 与攻防缓冲独立，出手／后摇／硬直结束后仍按住则恢复移动；提前松手就停止 |
| 待执行指令的释放 | 等待中的防御提前松手取消；完成的短按保留轻击，完成的重击释放保留蓄力时长与方向 |
| 技能排队 | 执行成功才扣技能点；覆盖或取消未执行技能不扣点 |
| 受击／硬直 | 取消右手攻防技能和待执行指令，保留未松手的左侧移动；硬直结束继续走位，硬直期间松手则停止，不误发轻击 |
| 暂停／取消／结束 | 失焦、暂停、旋转和结束清除全部触摸及待执行指令；指针取消不得误发攻击 |
| 撤退／暂停按钮 | 立即执行，不等待收招 |

左手在右手蓄力或举盾期间短按松手不会额外轻击；在无右手输入的后摇期间短按可排队轻击。
普通轻击默认沿当前朝向出招，重击使用玩家控制的朝向；自动朝向开关默认关闭。
技能与重击／防御共用右手通道，最多双指；训练场技能不限次数，正式模式保留原技能点规则。
操作偏好独立保存在本机浏览器，与养成存档分开，训练和正式模式共用。
