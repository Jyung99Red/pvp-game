# 战斗操作与调参（2026-09-13）

训练、正式 PVE、PVP 共用中央移动／攻击键，左上防御、右上四向技能。
以下输入规则为当前实现；文末 2026-09-11 记录只保留历史背景。

## 输入

- 中央按钮固定显示，每次落指点是本次手势原点；12 CSS px 为移动死区。
- 在原点短按松手：朝人物实际朝向轻击。先拖出死区：立即普通移动，
  此次手势永久锁定为移动，回原位停留也不会蓄力；松手只停步。必须重新按住才能蓄力。
- 原位按住 .25 秒识别蓄力；识别时间独立于武器伤害阈值，蓄力时间从识别点开始计算。
  进入蓄力后拖动同时移动、转向；移速为60%，转速为65%，满蓄不自动出刀。
- 以本次落指点为中心，24 CSS px 内为取消圈：圈内松手取消，圈外松手重击。
  取消圈跟随落指位置显示；圈内可以停步保留朝向。人物移动死区仍为12px，
  12–24px之间允许小幅走位，但松手仍属于取消。
- 松手使用当时人物实际朝向；快速反向拖动也必须经过转速推进，不能用拖动目标方向
  覆盖出刀方向。排队重击同样保存松手时实际朝向。轻击与举盾起手不会瞬间朝敌人吸附。
- 自动朝向默认关闭。开启后仅无有效移动方向的待机状态按转速转向敌人；
  移动跟随拖动方向，蓄力移动与方向绑定。PVE/PVP/训练采用相同规则。
- 左侧防御按住举盾，拖动仅转向；可与中央普通移动同时操作，举盾和防御期间
  移速30%、转速50%。主动蓄力与防御／技能互斥，需先释放或取消蓄力。
- 最多双指；同一按钮只能有一个手指。按在中央后拖到其他按钮上仍归中央手势，
  不跨键触发。第二根手指操作防御或技能时，中央待定短按不再触发轻击／长按蓄力。
- 右侧技能：上治疗2、右疾速2、下满蓄2、左弹反3 SP；超过24px才选择方向，
  约7度滞回防抖，松手释放。训练免费练习。技能排队成功执行后才扣点，
  满血治疗不扣点且不覆盖队列。
- 设置中的中心取消同时作用于重击和技能。关闭后原位松手也重击；技能沿用
  本次最后有效选择，从未选中的短按不施法。操作偏好独立于养成存档保存。
- 出招／后摇／受击硬直期间保留一个最新指令；被替换的蓄力不重新启动。
  受击清掉蓄力、盾／技能及待执行指令，保留中央按住的移动，硬直后续走；
  此次手势不再蓄力或轻击，硬直中松手就停止。
- 暂停、失焦、取消、旋转、结束会清空所有指针；PVP前后台规则仍按其协议执行。
  输入接口仅接受 move / guard / skill；action 是内部蓄力记录，不再是按钮或网络通道。

## 范围与动画

`spatialEngine.heavyShape(battle, charge)`按总蓄力比例同时插值射程60→103和
角度0.28π→0.68π。上限仍取`heavy.range/arc`，下限取`heavy.minRange/minArc`。
预览与释放后的命中快照调用相同计算；释放后范围/位置/朝向固定。
正式模式的增伤起点为武器 `chargeThresholdMs`，从起点后固定2秒达到满蓄
（basic/heavy/light 为 2.3/2.35/2.28 秒）；训练满蓄1.6秒，保持独立平衡。

武器沿扇形边缘从左往右挥动：蓄力时位于左边缘，释放后在前摇期间走到右边缘100%，
命中时保持该端点；后摇按剩余时间线性返回原位。轻击同样挥动。
武器固定32世界单位长度，轮廓与大小不随蓄力或攻击改变，仅转动角度。
范围提示继续使用实际攻击扇形；伤害仍在前摇结束时整片判定一次。
HP下降事件触发角色0.28秒红色闪烁；怪物冲击环和八向火花为0.18秒，伤害数字为0.55秒。
玩家硬直期间以橙色染色、脉冲环和头顶短线标识，硬直结束立即消失。
所有表现随模拟时间恢复，暂停冻结特效，不改变战斗坐标或命中判定。

## 移速与转速接口

基础参数位于`pve/spatial_data.js`：`playerSpeed=115`、`playerTurn=8 rad/s`、
`chargeMoveMultiplier=0.6`、`chargeTurnMultiplier=0.65`。

`config.motion`与buff均提供`move / turn / chargeMove / chargeTurn`四个独立乘数。
蓄力移速 = 基础移速 × move × 0.6 × chargeMove；蓄力转速 = playerTurn × turn × 0.65 × chargeTurn，不同buff相乘。
防御移速 = playerSpeed × move × guardMoveMultiplier(0.3)，
防御转速 = playerTurn(8) × turn × guardTurnMultiplier(0.5)。focus只管AP/SP恢复，不隐式改变走速。

装备效果类型：`spatial_move_speed`、`spatial_turn_speed`、`charge_move_speed`、
`charge_turn_speed`；value为增减比例，例如0.2表示+20%。由
`player.getSpatialMotion()`聚合并注入正式档案，现有装备不会自动获得新词条。

临时效果：`spatialEngine.setMotionBuff(battle, id, {move: 1.2, turn: 1.1}, seconds)`。
同id替换，不同id叠乘；缺省乘数为1，允许0表示锁定该速度，不接受负数或无穷值。
持续时间使用战斗模拟秒，暂停不消耗，下一场不继承。

## 最新参数与技能（2026-09-11 第三次试玩反馈）

蓄力转速按“降低5个百分点”从70%改为65%：基础8×0.65=5.2 rad/s，约298°/秒。
重击前摇0.22秒、后摇0.60秒；轻击维持0.10/0.28秒。
治疗消耗2点，回复最大HP的30%；满血请求不排队、不扣点，执行时再次检查HP。
疾速消耗2点，持续10秒；保留1.5倍蓄力进度速度，新增移速×1.10、非蓄力转速×1.05。
移速增益作用于普通/蓄力/防御；转速增益只作用于普通移动转向和防御，不作用于蓄力。
重复使用刷新10秒，不叠加；满蓄2点、弹反3点，均为一次效果。
转速计算：每帧最大转角=基础角速度(rad/s)×状态倍率×装备/buff倍率×dt；沿最短角差转向，不越过目标。
默认普通8、疾速普通8.4、蓄力5.2、防御4、疾速防御4.2 rad/s。
自动朝向模式仍直接面向敌人，手动转速约束用于手动转向。
本轮仅语法/差异静态检查，未运行回归或设备测试。
