# 重击操作与调参（2026-09-11）

正式地下城与训练页共用新手势。用户要求本轮不测试，修改后直接交付试玩；
旧报告中的32项通过属于上一版本，旧的原地蓄力/向上释放断言待下一次测试时更新。

## 输入

- 左侧动态移动区：以每次落指点定位摇杆，拖出12 CSS px死区移动，轻点松手轻击。
  松手、取消、失焦、暂停、旋转屏幕后隐藏摇杆并清空输入；下次按下重新定位。
- 右侧四宫格：左上防御、右上技能、左下重击、右下预留；技能方向标签仅按住时展开。
  左侧动态移动区域向下移，底部与右侧操作区对齐。
- 重击键按下立即蓄力，拖动只转向；防御键按住举盾，拖动只转向。
- 左右输入独立，最多两指：左手移动可与右手重击蓄力或举盾并行；
  重击与防御互斥，蓄力必须先释放或取消才能举盾。
- 蓄力时，以按钮几何中心为原点：18 CSS px内为取消区，按钮变红。
  中心外任意方向松手释放重击，中心内松手取消，不扣AP。
  「暂停 / 设置 → 玩家操作」可关闭中心取消，关闭后中心松手也释放重击。
- 四向技能按钮：上治疗2点、右疾速2点、下满蓄2点、左弹反3点。
  手指拖动超过24 CSS px且离开按钮中心24px死区才选中；四方向边界约7°滞回防抖。
  松手释放，中心取消开启时回中心松手不释放；关闭时使用本次最后有效方向。
  从未拖出死区始终不释放；取消事件不释放。训练场技能不限次数，正式模式按原规则扣点。
  技能与重击／防御右手互斥，左手仍可移动，所有通道合计最多双指。
- 角色只沿左手拖动方向移动；右手按转速逐渐转向。右键中心内保留朝向，
  不影响左手移动；蓄力移动维持70%速度，蓄力转速为65%，防御移速为正常30%、转速为正常50%，举盾起手也生效。
  正常释放使用当前朝向，不自动转回敌人。满蓄不会自动出手。
- 默认关闭自动朝向：普通移动按转速朝向移动方向，停手保留朝向；轻击不自动追踪。
  玩家操作设置可开启自动朝向，恢复待机、轻击和举盾起手时朝向怪物。
  两项偏好由`core/combat_settings.js`独立保存到localStorage，训练与正式模式共用，不进入养成存档。
- 出手/后摇/受击硬直期间保留一个下一指令，后来的输入覆盖先前输入。
  轻击、蓄力、重击、移动、防御及正式技能均可等待。
  左手移动独立保持，攻击/后摇/硬直结束后恢复，不覆盖右手待执行指令。
  提前松开移动/防御会取消对应等待；右手仍在蓄力或举盾时，左手松手不会额外出刀。
  后摇期间完成的短按会留下轻击；完成的蓄力释放会保留蓄力时长与释放方向。
  技能点仅在实际执行成功时扣除，覆盖或取消排队不收费。
- 受击只取消右手攻防/技能及待执行指令，保留仍按住的左手移动；硬直期间停步，结束后自动续走。
  硬直期间松手立即清空移动，原有按住不会误变成轻击；暂停/失焦/旋转/结束仍清空所有输入。
  撤退与暂停始终立即执行。

## 范围与动画

`spatialEngine.heavyShape(battle, charge)`按蓄力比例同时插值射程60→103和
角度0.28π→0.68π。上限仍取`heavy.range/arc`，下限取`heavy.minRange/minArc`。
预览与释放后的命中快照调用相同计算；释放后范围/位置/朝向固定。
正式满蓄2秒，训练满蓄1.6秒；伤害继续使用各自曲线。

武器沿扇形边缘从左往右挥动：蓄力时位于左边缘，释放后在前摇期间走到右边缘100%，
命中时保持该端点；后摇按剩余时间线性返回原位。轻击同样挥动。
武器固定32世界单位长度，轮廓与大小不随蓄力或攻击改变，仅转动角度。
范围提示继续使用实际攻击扇形；伤害仍在前摇结束时整片判定一次。
HP下降事件触发角色0.28秒红色闪烁；怪物冲击环和八向火花为0.18秒，伤害数字为0.55秒。
玩家硬直期间以橙色染色、脉冲环和头顶短线标识，硬直结束立即消失。
所有表现随模拟时间恢复，暂停冻结特效，不改变战斗坐标或命中判定。

## 移速与转速接口

基础参数位于`pve/spatial_data.js`：`playerSpeed=115`、`playerTurn=8 rad/s`、
`chargeMoveMultiplier=0.7`、`chargeTurnMultiplier=0.65`。

`config.motion`与buff均提供`move / turn / chargeMove / chargeTurn`四个独立乘数。
蓄力移速 = 基础移速 × move × 0.7 × chargeMove；蓄力转速 = playerTurn × turn × 0.65 × chargeTurn，不同buff相乘。
防御移速 = playerSpeed × move × guardMoveMultiplier(0.3)，
防御转速 = guardTurn(8) × turn × guardTurnMultiplier(0.5)。现有spd属性仍管AP恢复，不隐式改变走速。

装备效果类型：`spatial_move_speed`、`spatial_turn_speed`、`charge_move_speed`、
`charge_turn_speed`；value为增减比例，例如0.2表示+20%。由
`player.getSpatialMotion()`聚合并注入正式档案，现有装备不会自动获得新词条。

临时效果：`spatialEngine.setMotionBuff(battle, id, {move: 1.2, turn: 1.1}, seconds)`。
同id替换，不同id叠乘；缺省乘数为1，允许0表示锁定该速度，不接受负数或无穷值。
持续时间使用战斗模拟秒，暂停不消耗，下一场不继承。

## 最新参数与技能（2026-09-11 第三次试玩反馈）

蓄力转速按“降低5个百分点”从70%改为65%：基础8×0.65=5.2 rad/s，约298°/秒。
重击前摇0.22秒、后摇0.60秒；轻击维持0.10/0.28秒。
治疗消耗2点，回复最大HP的30%；满血请求不排队、不扣点，执行时再次检查HP。
疾速消耗2点，持续10秒；保留1.5倍蓄力进度速度，新增移速×1.10、非蓄力转速×1.05。
移速增益作用于普通/蓄力/防御；转速增益只作用于普通移动转向和防御，不作用于蓄力。
重复使用刷新10秒，不叠加；满蓄2点、弹反3点，均为一次效果。
转速计算：每帧最大转角=基础角速度(rad/s)×状态倍率×装备/buff倍率×dt；沿最短角差转向，不越过目标。
默认普通8、疾速普通8.4、蓄力5.2、防御4、疾速防御4.2 rad/s。
自动朝向模式仍直接面向敌人，手动转速约束用于手动转向。
本轮仅语法/差异静态检查，未运行回归或设备测试。
