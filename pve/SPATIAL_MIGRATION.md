## 迁移时的规则与兼容清单（2026-09-09历史）

| 项目 | 状态与规则 |
|---|---|
| 等级、HP、攻击、防御、强化 | 已接入 `player.getStats()`，开战生成档案；跨层 HP 携带 |
| 轻击 | 攻击力 ×0.3，取整至少 1，再应用防御；短按无惩罚伤害 |
| 重击 | 攻击力 ×(0.3 + 0.8 ×进度)；2 秒满蓄，满蓄不自动出手 |
| 蓄力词条 | 进度 = clamp((蓄力秒数−词条秒数)/(2−词条秒数),0,1)；门槛裁剪到 0～1.9 秒。240ms 手势阈值不变 |
| 防御 | 沿用旧核心减伤函数：原伤害减 min(原伤害×20%, 防御×15%)，至少 1 |
| 格挡减伤词条 | 防御处理后的伤害 ×0.4 × `getGuardDamageMultiplier()`；训练场保持 0.25 |

| 荆棘 | 格挡反射原伤害的词条比例并经过敌人防御；双死败北 |
| AP 上限词条 | 已接入，恢复不越界，HUD 动态生成数量 |
| 双手装备时序 | 继续按原槽位顺序选第一个时序词条 |
| 治疗（3点） | 引擎治疗最大 HP 的30%，唯一 HP 写入入口 |
| 疾速（1点） | 10秒蓄力速度×1.5，按模拟时间累计，到期不倒退；不改变手势识别 |
| 满蓄（2点） | 当前正在蓄力则填满，否则排队给下一次长按；仍需上划释放。取消不退技能点或已用效果，不消耗攻击 AP |
| 自动弹反（2点） | 下一次空间范围内原本会直接受击的攻击触发，豁免朝向/AP并保持当前蓄力；不消耗普通格挡上的护体次数 |
| 精准防御反击 | 攻击力×0.5经过敌人防御；普通弹反消耗0.5 AP，护体不消耗 AP |
| Boss 连段/狂暴 | 已适配：连段概率/上限来自旧AI；缩短收招并保留下一招起手。狂暴阈值和伤害倍率保留，速度倍率作用敌人动作计时/AP恢复 |

| 旧怪物举盾AI/拼刀 | 不适用于当前空间模式；由范围/锁向/走位/失衡取代。没有静默恢复全场命中 |
| 怪物招式 | 所有10个敌人（包括测试木桩）都有显式配置；当前全部楼层池与Boss覆盖。伤害倍率不决定起手 |

## 时序、HP和生命周期

正式引擎采用10ms固定子步；每帧至多推进100ms，失焦/切后台暂停并释放输入，点击继续后重置帧时间。
同一步依次处理玩家、敌人、场地伤害，再统一检查终局；双方死亡败北优先。
玩家重击触发失衡仍可取消敌人尚未生效的动作，这是显式的失衡规则。
训练场继续保留玩家致命命中先结束的原型顺序。

- 活动战斗：引擎每模拟1秒处理温泉，每2秒处理被动恢复；`tick.js`不写第二份HP。
- 暂停：战斗回血、动作、技能时间、场地效果全部停止；世界时钟可继续。
- 等待楼层选择：保持旧tick回血规则，后台不回复；下一层读取已恢复的HP。
- 结束/基地：沿用基地回血；死亡回城恢复10%HP。瞬时位置与输入不存档。

胜利只结算一次经验、材料、runGold；Boss检查点只向前推进；回城只银行入账一次；死亡丢失runGold。
`battleId`、`settled`、`ended` 和当前实例的输入监听组隔离防止旧局污染。切层销毁输入监听与ResizeObserver，
结束停止rAF；任何时候最多一个PVE循环。

## 文件与清理

- `core/spatial_combat.js`：几何及墙边碰撞；移动不推动静止的防御者。
- `core/combat_gestures.js`、`ui/combat_input.js`：共享手势及捕获。
- `pve/spatial_data.js`：训练预设、所有正式招式模板。
- `pve/pve_profiles.js`：装备成长档案映射。
- `pve/spatial_engine.js`：共享动作、伤害、HP、技能、AI。
- `pve/pve_logic.js`：正式地下城、奖励及场地适配。
- `ui/ui_spatial_battle.js`、`pve/ui_pve.js`、`pve/spatial_pve.css`、`partials/pve-battle.html`：正式视图，ID前缀`pve-s-`。
- `index.html`：只加载空间 PVE 引擎、UI 和 partial；旧 PVE 回退入口已移除。
- 用户于 2026-09-10 试玩确认后授权清理：旧 PVE 引擎、UI、partial、训练别名及废弃 AI 参数已删除。

PVP脚本、协议和`core/combat_resolver.js`保持原样；正式档案仍复用其AP恢复公式。新空间模式不调用旧交锋判定。
存档key/格式保持v1；没有读取、清空或更改用户原origin的存档。
